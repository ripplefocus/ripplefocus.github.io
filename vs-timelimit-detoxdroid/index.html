涟漪和 TimeLimit.io、DetoxDroid 怎么选

TimeLimit.io 和 DetoxDroid 都是免费开源的安卓 App，在 F-Droid 和 GitHub 上常被推荐。TimeLimit.io 是按家长和孩子来设计的，DetoxDroid 是让自己的手机变得没那么好玩。涟漪也免费，只在一台手机上用，不用注册，家长给孩子手机设置和大人管自己都能用。我是涟漪的开发者，看的时候请记住这一点。涟漪安卓版 v0.1.25，iPhone 版 v0.1.5。TimeLimit.io 的信息来自 2026 年 11 月的 F-Droid 页面（v7.9.0），DetoxDroid 的信息来自同期的 GitHub 说明（v3.0.1）。

三个分别是什么

TimeLimit.io

开源（GPL-3.0），F-Droid 上架，要安卓 8.0 及以上。把 App 分到不同分类，每个分类设允许的时段和时长规则，可以按天，也可以按几天合计，比如整个周末。家长可以额外加时间当奖励，也可以临时关掉限制一小时或一整天。一台设备上能建家长和孩子多个用户，一个孩子的时长也能跨几台设备合计。联网模式下家长能在别的设备上查看和改设置，不用自己的服务器的话，部分联网功能在德国每月 1 欧元或每年 10 欧元。F-Droid 页面写着在部分品牌上效果不好，主要是华为和 Wiko。

DetoxDroid

开源（GPL-3.0），从 GitHub Releases 安装。能把选中的 App 变成黑白、调暗加模糊，一直开着勿扰，检测到长时间刷屏会打断并锁住那个信息流一段时间，还能让 App 打开前先等几秒、挡一个提醒页或者直接停用。设了每日时间预算的 App 用完就锁。有暂停按钮（两次暂停之间有最短间隔）、在一段时间里关掉所有退路的紧急刹车、给设置加口令、极简桌面小组件和屏幕时间小组件。它是给自己用的，没有家长和孩子的设置。

涟漪

免费 App，没有广告，不用注册，也没有订阅。涟漪不开源，也没上 F-Droid。安卓版（8.0 及以上）有自律时段、每个 App 的每日时长（可以设 0 分钟）、打开次数上限、连续使用后休息、一键专注、限制网址、使用统计日历、只拦视频号和朋友圈，还有严格模式。iPhone 版 v0.1.5 只能按时段屏蔽、防删除 App、防改时间和用解锁码。没有家长端，不发报告。

孩子的手机

几个孩子或者共用一台平板

TimeLimit.io 这点做得好，能建多个孩子用户，时长还能跨设备合计。涟漪一台手机只有一套规则，共用的平板每个人都是同样的限制。

在自己手机上改规则

TimeLimit.io 的联网模式可以。涟漪不行，规则要拿着孩子的手机当面改。

孩子撤不掉的规则

涟漪开严格模式，解锁码家长自己记着。开严格模式会同时开防卸载，要安卓 11 及以上。改系统时间也结束不了时段。忘了解锁码，申请 72 小时后解除。TimeLimit.io 用设备管理器权限发现自己被卸载。

某个游戏彻底不让玩

涟漪里把这个游戏设成 0 分钟，一整天打不开，别的 App 照样按各自的时长。

孩子用 iPhone 或 iPad

TimeLimit.io 和 DetoxDroid 都是安卓 App。涟漪 iPhone 版 v0.1.5 只能按时段屏蔽，解锁码家长保管。系统自带的屏幕使用时间加家人共享免费，能做的更多。

大人自己的手机

让手机没那么好玩

DetoxDroid 有涟漪没有的功能，比如黑白屏、模糊和打断无限刷。如果你还是想打开 App，只是想让它没那么吸引人，可以先试它。

每个 App 一个硬上限

涟漪给每个 App 单独设每日时长，比如小红书每天 20 分钟，工作日游戏 0 分钟，还能限制一天打开几次。

让限制撤不掉

涟漪里放松规则或卸载要先等 15 分钟或输解锁码。开了严格模式只能用解锁码，一天最多成功用 3 次，可以把解锁码交给伴侣或朋友。DetoxDroid 有紧急刹车和设置口令，用途差不多。

怎么选

选 TimeLimit.io

想要开源的家长管控，有几个孩子或几台设备，可能还想在别的设备上改规则。

选 DetoxDroid

想要开源工具，让自己的手机用起来更无聊，要黑白屏和打断刷屏。

选涟漪

想在安卓上按 App 设硬上限，不注册、不往外发数据，解锁码可以交给别人保管，给自己用，或者给能当面设置的孩子手机用。

先试一下

装最新版 APK，按提示开启无障碍服务，给一个 App 设 30 分钟每日时长，打开看看会不会弹拦截页。

常见问题

涟漪开源吗？

不开源。涟漪免费，没有广告，不用注册，但源代码没有公开，也没上 F-Droid。最看重开源的话，TimeLimit.io 和 DetoxDroid 都不错。

涟漪和 DetoxDroid 能一起装吗？

能一起装，但两个都要用无障碍服务，先在自己手机上试一下。我没有测过两个一起用。

涟漪真的免费吗？

是的，没有广告，没有订阅，不用注册。更多见 常见问题。

iPhone 版能做什么？

涟漪 iPhone 版 v0.1.5 可以按时段屏蔽 App，能防止删除 App、防改时间，也能用解锁码。没有每日时长。
