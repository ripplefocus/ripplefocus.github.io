走亲戚、家庭聚会时一直刷手机怎么设

过年过节回老家走亲戚，周末一大家子聚在一起吃饭，或者和朋友约了聚餐，人坐在桌边，手里还在刷短视频、短剧。长辈问了两遍才听见，一顿饭下来没说上几句话。孩子到了亲戚家也一样，大人一聊天，就把平板或旧手机塞给他，几个孩子凑在一起玩游戏、看视频，一玩就是一下午。站内的 吃饭时 页讲自己家里每天吃饭，周末假期 页讲在家躺着刷，出游 页讲路上，这一页讲去别人家或者和亲友聚在一起的那几个小时。涟漪只管装了它的手机和平板，亲戚家的手机、平板和电视它管不到，这部分要靠大人之间提前说好。下面前一部分写大人怎么给自己设，后一部分写家长怎么管孩子带去的平板和手机。安卓最新是 v0.1.18，iPhone 是 v0.1.5，两边能力不一样，文中分开写。

成年人：和亲友坐在一起的时候少看手机

出门前开一键专注

聚会一般就几个小时。出门前在安卓上点一键专注，时长按聚会长短来定，比如 3 小时。选「只锁我选的 App」，把短视频、短剧和游戏选上，微信、电话、地图和打车不选，找路、联系人都不受影响。说明见 一键专注页面。

给短视频短剧设每日时长和打开次数

过节那几天天天有饭局，每次都开专注容易忘。可以直接给短视频和短剧设每天最多用多久，按分钟自定义，也可以设成 0 分钟整天禁用。再设每天最多打开几次，打开「每次打开先等一会儿」，桌上聊天冷场时想掏手机，会先停一下。短剧见 短剧页面，打开次数见 打开次数页面。

聚会时间固定就建时段

有的家庭每周日中午固定聚餐。建一个周日中午的时段，只把短视频、短剧和游戏放进名单，到点这些 App 打不开，结束后自动恢复。

视频号和朋友圈可以先给几分钟

聚会时少不了在微信群里发照片。安卓上可以只限制微信里的视频号和朋友圈：先给一段短时间，用完要写理由再续，每天最多续 3 次，时间算进微信每日时长。严格模式开启时改用解锁码续时。微信聊天、发照片和语音电话照常能用。

怕自己关掉就开严格模式

饭桌上无聊时顺手把规则关了，就开严格模式。把至少 8 位的解锁码交给家里人，想放松规则得找对方要码，解锁码每天最多成功用 3 次。开启严格模式时会同时开防卸载。忘了码可以申请 72 小时后解除。详情见 严格模式页面。

家长：孩子到了亲戚家，拿着平板玩一下午

孩子自己的平板或旧手机先设好每日时长

去亲戚家之前，在孩子常用的安卓平板或旧手机上给游戏和短视频设每日时长，用完就打不开，几个孩子凑在一起也玩不过当天的额度。某个游戏特别停不下来，可以设成 0 分钟，回家以后再放开。游戏怎么设见 手机游戏页面。

解锁码家长自己保管

孩子玩到额度用完，常会去找长辈帮忙解开。解锁码只有家长知道，亲戚想帮也解不开。安卓开防卸载，孩子删不掉涟漪。需要更稳可以开严格模式，开启时会同时开防卸载。

调系统时间也没用

大一点的孩子会把系统时间往后调，想让额度提前刷新。涟漪安卓按开机以来的时间计时，改系统时间不会多出时间。说明见 防改时间页面。

分屏、小窗和画中画也会拦

有的孩子会把视频拖到小窗或画中画里，一边玩一边看。安卓上放进名单的 App 在分屏、小窗和画中画里也会被拦，时间算进当天用量。OPPO 手机上的小窗只能被遮住并静音，小窗本身要手动关掉。

亲戚家的设备要提前说

涟漪管不了亲戚家的手机、平板和电视。孩子拿表哥表姐的手机玩，只能靠大人之间先打个招呼。如果孩子用的是 iPhone，v0.1.5 可以按时段屏蔽 App、禁止删除 App、防改时间和设解锁码；每日时长、0 分钟、打开次数、一键专注、严格模式和视频号续时目前只有安卓有。家长控制总览见 家长控制页面。

常见问题

走亲戚、家庭聚会时总忍不住低头刷短视频，怎么管？

用涟漪安卓 v0.1.18，出门前开一键专注，只锁短视频、短剧和游戏，时长按聚会长短来定。过节天天有饭局，可以直接给这些 App 设每日时长和打开次数。微信聊天、电话和地图照常用。怕自己关掉就开严格模式，把解锁码交给家人。

孩子到亲戚家拿平板玩一下午游戏，怎么设？

出发前在孩子的安卓平板或旧手机上给游戏和短视频设每日时长，或者把某个游戏设成 0 分钟。解锁码由家长保管，开防卸载，涟漪按开机以来的时间计时，调系统时间也没用。亲戚家的手机和平板涟漪管不了，需要大人之间提前说好。

涟漪能管亲戚家的手机或电视吗？

不能。涟漪只管装了它的安卓手机、安卓平板和 iPhone 上的 App，别人的手机、平板和电视都不归它管。

和「吃饭时」「周末假期」页有什么不同？

吃饭时 讲自己家里每天吃饭，周末假期 讲在家躺着刷一整天，出游 讲坐车和旅途。这一页讲去亲戚家或者和亲友聚餐的那几个小时。更多说明见 常见问题。

iPhone 版有这些功能吗？

iPhone 版目前是 v0.1.5，可以按时段屏蔽 App、禁止删除 App、防改时间和设解锁码，没有每日时长、打开次数、0 分钟、一键专注、严格模式、视频号续时和限制网址。
