Ripple privacy policy

Last updated: November 13, 2026

What stays on your phone

Ripple does not require an account. There are no ads and no in-app purchases.

Your rules, unlock codes and usage stats are stored only on your phone. Ripple does not send which apps you use, how long you use them, how many times you open them, your unlock code, or any personal content.

Once-a-day anonymous count

Since version 0.1.6, the first time you open Ripple each day it sends one anonymous count. This is used to see how many devices use each version. The count goes to GoatCounter and to PostHog (US Cloud).

GoatCounter receives the platform (Android or iOS), the app version, install age as a range (the same day, 1 to 6 days, 7 to 29 days, or 30 days and more), whether this is a new install or an update, and a random install ID made on the phone.

PostHog receives the platform, the app version and version code, the exact number of days since install, whether this is a new install or an update, the language you use in the app (English or Chinese), whether the phone is marked as a test device, and the same random install ID. Ripple asks PostHog not to store the IP address.

The random ID is not your device ID, advertising ID or IMEI. It is not linked to your name, phone number or contacts. If you uninstall and reinstall, a new ID is made. These counts do not include which apps you use or how long you use them.

Checking for updates

When you check for updates, Ripple uses the network to get a new version from the official release channel.

Advanced Protection

If you turn on optional Advanced Protection, the phone completes a wireless debugging handshake on the device itself. That handshake does not send your data off the phone.

Permissions

Ripple uses the Accessibility service and usage access only on the phone, to see which app is in the foreground and to block it according to your rules. That information is not uploaded.

This website

This website uses GoatCounter to count page views. It does not set advertising cookies.
