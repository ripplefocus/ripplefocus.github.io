培训班接送和等候区刷不停，怎么设

接孩子上下兴趣班、补习班，门口和等候区一坐就是一两小时，短视频很容易刷过头。孩子课前课后也在刷。下面前一部分写大人怎么给自己设接送等候时的限制，后一部分写家长怎么管孩子在培训前后刷。安卓最新是 v0.1.17，iPhone 是 v0.1.5，两边能力不一样，文中分开写。站内另有 上学时段 和 写作业 页，这一页专门讲培训班接送和机构等候区这一段。

成年人：接送等候少刷

先建一个放学后接送时段

把短视频、短剧、直播、游戏放进名单，设比如 16:00 到 20:00，或者按你家孩子常去培训班的时段来。到点这些 App 打不开，微信聊天、电话和导航照常用。只在周末送课的，可以只设周末那几段。

用每日时长和打开次数管住「再等一会儿」

给常刷的 App 设每天最多用多久，可按分钟自定义，也可以设成 0 分钟整天禁用。再设每天最多打开几次，并打开「每次打开先等一会儿」，手伸出去会先停一下，不容易在门口一刷就是整节课。

视频号和朋友圈可以先给几分钟

安卓上微信可以只限制视频号和朋友圈：先给一段短时间，用完要写理由再续，每天最多续 3 次，时间算进微信每日时长。严格模式开启时改用解锁码续时。接送时想回几条家长群消息，聊天本身不受影响。

临时要盯门口接人就开一键专注

课快下了、人多不好找，或者估计还要等很久但不想刷过头，可以开一键专注，把短视频和游戏先锁住，到点自动结束。

怕自己在等候区又关掉就开严格模式

把至少 8 位的解锁码交给家人或同事，开严格模式。想放松规则只能输对方手里的码。开启严格模式时会同时开防卸载。忘了码可以申请 72 小时后解除。

家长：孩子培训前后刷

给孩子设培训日放学后时段

孩子到机构门口、课间休息或下课后很容易刷。可以在孩子手机上建一个放学后时段，比如 16:00 到 20:00，把短视频和游戏放进名单。解锁码由家长保管。

平时留一点额度，培训日想严一点就用 0 分钟

平时可以给短视频留每天 20 到 40 分钟和有限打开次数。培训日容易一刷就是一两小时的，可以把游戏和短视频临时设成 0 分钟，课上完再改回来。

等候区里刷也拦得住

时段和每日时长按 App 生效，在机构沙发上刷一样会被拦。安卓打开防卸载，需要时开严格模式。涟漪按开机以来的时间计时，孩子把系统时间往回调，限制照样生效。

家长自己的手机也设同样的接送限制

大人一边刷、孩子一边看，孩子更难停。家长先在自己手机上设同样的放学后或接送限制，孩子更愿意配合。写作业可以参考 写作业页面。

孩子用的是 iPhone

iPhone 版目前是 v0.1.5，可以按时段屏蔽 App、禁止删除 App、防改时间和设解锁码，放学后培训时段能设。打开次数、每日时长、0 分钟、一键专注、严格模式、视频号续时和限制网址目前只有安卓有。

安装或升级到最新版

安卓下载最新版 APK，按引导开启无障碍服务。已经装了旧版的，在「设置 › 关于 › 检查更新」里升级。iPhone 装 v0.1.5，需要 iOS 16 及以上。

建放学后接送或培训时段

把短视频、短剧、直播、游戏放进名单。成年人比如 16:00 到 20:00，或按常去培训班的时段设。孩子可以设同样的放学后窗口。

给常刷的 App 设每日时长和打开次数

短视频、微博、小红书先设每天最多用多久和打开几次。接送特别停不下来的，可以设成 0 分钟。微信视频号可以单独用「先给几分钟」的方式。

设解锁码，孩子手机开防卸载

大人把解锁码交给家人，孩子手机上的码由家长保管。安卓开防卸载，需要更稳可以开严格模式。iPhone 开启禁止删除 App。

常见问题

接孩子上下培训班总忍不住刷短视频，怎么管？

用涟漪安卓 v0.1.17 建放学后接送时段，把短视频放进名单。再给这些 App 设每日时长和打开次数。课快下了可以开一键专注。怕自己关掉就开严格模式，把解锁码交给别人。

孩子在机构等候区一直刷，怎么设？

在孩子手机上建放学后时段，解锁码家长保管，打开防卸载。安卓改系统时间没用。培训日想更严可以把短视频设成 0 分钟，课上完再改回来。

周末兴趣班也适用吗？

适用。可以把时段只设在周末下午，或者工作日和周末各建一段。

iPhone 版有这些功能吗？
