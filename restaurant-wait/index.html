饭店餐厅等餐落座刷不停，怎么设

在饭店或餐厅等上菜，或者落座等人，很容易刷起短视频或短剧，一抬头菜凉了、同桌的人等了半天。带孩子吃饭时，大人在刷，孩子一拿到手机也跟着刷。站内另有 咖啡馆奶茶店、吃饭时、做饭时 和 排队候诊 页，这一页专门讲饭店餐厅等餐落座这一段。下面前一部分写大人怎么给等餐少刷，后一部分写家长怎么管孩子在餐厅刷。安卓最新是 v0.1.16，iPhone 是 v0.1.5，两边能力不一样，文中分开写。

成年人：等餐落座少刷

先建一个外出或周末时段

把短视频、短剧、直播、游戏放进名单，设比如周五到周日晚饭前后，或者你常在外吃饭的那几段。到点这些 App 打不开，微信聊天、电话和支付照常用。只在周末下馆子的，可以只设那几段。

用每日时长和打开次数管住「再刷一条」

给常刷的 App 设每天最多用多久，可按分钟自定义，也可以设成 0 分钟整天禁用。再设每天最多打开几次，并打开「每次打开先等一会儿」，餐厅座位上手伸出去会先停一下，不容易一刷就半小时。打开次数的说明见 打开次数页面。

快上菜或要点单就开一键专注

服务员快来了、要点菜、或者估计还要等一会儿但不想刷过头，可以开一键专注，把短视频和游戏先锁住，到点自动结束。电话和支付照常用。一键专注的说明见 一键专注页面。

视频号和朋友圈可以先给几分钟

安卓上微信可以只限制视频号和朋友圈：先给一段短时间，用完要写理由再续，每天最多续 3 次，时间算进微信每日时长。严格模式开启时改用解锁码续时。等餐时想回几条消息，聊天本身不受影响。

怕自己在座位上又关掉就开严格模式

把至少 8 位的解锁码交给家人，开严格模式。想放松规则只能输对方手里的码。开启严格模式时会同时开防卸载。忘了码可以申请 72 小时后解除。详情见 严格模式页面。

家长：带孩子吃饭也刷

给孩子设外出或周末时段

家长在旁边刷，孩子很容易要手机。可以在孩子手机上建一个外出或周末时段，比如周五到周日晚饭前后，把短视频和游戏放进名单。解锁码由家长保管。电话不要放进名单。

平时留一点额度，下馆子那天容易刷过头就用 0 分钟

平时可以给短视频留每天 20 到 40 分钟和有限打开次数。去饭店、餐厅特别停不下来的，可以把游戏和短视频临时设成 0 分钟，吃完回家后再改回来。

餐厅座位上刷也拦得住

时段和每日时长按 App 生效，在饭店或餐厅座位上刷一样会被拦。安卓打开防卸载，需要时开严格模式。涟漪按开机以来的时间计时，孩子把系统时间往回调，限制照样生效。

家长自己的手机也设同样的外出限制

大人一边刷、孩子一边看，孩子更难停。家长先在自己手机上设同样的外出时段，孩子更愿意配合。上了菜以后怎么管饭桌，可以参考 吃饭时页面；在家边做菜边刷可以参考 做饭时页面；咖啡馆奶茶店可以参考 咖啡馆奶茶店页面。

孩子用的是 iPhone

iPhone 版目前是 v0.1.5，可以按时段屏蔽 App、禁止删除 App、防改时间和设解锁码，外出或周末时段能设。打开次数、每日时长、0 分钟、一键专注、严格模式、视频号续时和限制网址目前只有安卓有。

设置步骤（安卓 v0.1.16）

安装或升级到最新版

安卓下载最新版 APK，按引导开启无障碍服务。已经装了旧版的，在「设置 › 关于 › 检查更新」里升级。iPhone 装 v0.1.5，需要 iOS 16 及以上。

建外出或周末时段

把短视频、短剧、直播、游戏放进名单。成年人比如周五到周日晚饭前后，或按常下馆子的时间设。孩子可以设外出或周末窗口。支付、电话不要放进名单。

给常刷的 App 设每日时长和打开次数

短视频、微博、小红书先设每天最多用多久和打开几次。等餐时特别停不下来的，可以设成 0 分钟。微信视频号可以单独用「先给几分钟」的方式。

设解锁码，孩子手机开防卸载

大人把解锁码交给家人，孩子手机上的码由家长保管。安卓开防卸载，需要更稳可以开严格模式。iPhone 开启禁止删除 App。

常见问题

饭店或餐厅等上菜总忍不住刷短视频，怎么管？

用涟漪安卓 v0.1.16 建外出或周末时段，把短视频放进名单。再给这些 App 设每日时长和打开次数。快上菜或要点单可以开一键专注。怕自己关掉就开严格模式，把解锁码交给别人。电话和支付照常用。

已经坐在座位上刷过头，怎么设？

和等叫号一样，建外出时段，把短视频和游戏放进名单。需要点菜、回几条消息时，用一键专注先锁住短视频。聊天和支付不受影响。

带孩子吃饭，孩子一拿到手机就刷，怎么设？

在孩子手机上建外出或周末时段，解锁码家长保管，打开防卸载。安卓改系统时间没用。想更严可以把短视频设成 0 分钟，吃完回家后再改回来。

和「咖啡馆奶茶店」「吃饭时」「做饭时」「排队候诊」页有什么不同？

咖啡馆奶茶店 讲等出餐和落座等人，吃饭时 讲上了菜以后的饭桌，做饭时 讲在家边做菜边刷，排队候诊 讲医院银行办事大厅。这一页专门讲饭店餐厅等餐落座刷不停，并按安卓 v0.1.16 的每日时长、打开次数、一键专注、严格模式和视频号续时来写。更多说明见 常见问题。

iPhone 版有这些功能吗？

iPhone 版目前是 v0.1.5，可以按时段屏蔽 App、禁止删除 App、防改时间和设解锁码，没有每日时长、打开次数、0 分钟、一键专注、严格模式、视频号续时和限制网址。
