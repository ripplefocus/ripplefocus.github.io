Working in another city, with a child at home

Many parents work in another city and see their child a few times a year. The evenings in a rented room are quiet, so the phone fills them, often until well after midnight. Back home the child lives with grandparents, who find it hard to say no and do not know the phone settings. I make Ripple, a free app blocker. Ripple for Android is v0.1.20 and Ripple for iPhone is v0.1.5. Ripple has no remote management, so everything on this page is set up on the phone itself, ideally during a visit home. The first part is for your own phone and the second part is for the child's phone.

Your own phone in the evenings

A sleep schedule that keeps calls

Add a schedule such as 23:30 to 7:00 with short video, short drama and game apps. A schedule only blocks the apps on its list, so WeChat calls with home keep working. If you want to keep WeChat and close only Channels or Moments, Ripple can block just those parts.

A daily limit for the evening app

Most people have one app that takes the whole evening. Give it a daily limit such as 45 minutes. When the time is used up the app shows the block screen until the next day.

Fewer quick opens

A daily open limit and a 5 to 30 second pause before opening help when you pick up the phone out of habit. The pause shows how long you have already used the app today. See open limits.

Give the code to someone at home

Without strict mode, loosening a rule needs a 15 minute wait (30 minutes for apps like Douyin) or the unlock code. With strict mode only the code works, at most 3 successful uses a day. Your partner at home can keep the code and read it out on a call when there is a real reason.

Look at the month

The usage calendar on Android shows each day's total and each app's time, opens and blocks, kept on the phone for 365 days. It is easy to see which nights went long.

If you use an iPhone

Ripple for iPhone v0.1.5 blocks apps by schedule, can stop apps being deleted, protects against clock changes and uses an unlock code. It has no daily limits or open limits.

The child at home with grandparents

Set it up during a visit

Ripple has no remote management, so you cannot change the child's rules from your own phone. Install it and set the rules while you are home, for example over a holiday, and check them again on the next visit.

School day schedules

Add a schedule for homework time and one for school nights, such as 21:00 to 7:00, with games, short video and live streaming apps. A 0 minute limit keeps one app closed all day. Calls, SMS, alarms and the camera keep working.

Keep the code yourself

Turn on strict mode and keep the unlock code with you in the other city. Grandparents do not need to know the settings, and they cannot be talked into loosening them. If the child needs more time for a good reason, you can read the code out on a call. Anti-Uninstall turns on with strict mode and needs Android 11 or later.

Clock changes and a lost code

Time is counted from device uptime, so changing the clock does not end a schedule. If you forget the code it can be requested and is lifted after 72 hours.

Keep it running on old phones

Older phones and some brands stop background apps, and then blocks stop too. Follow the keep alive guide for the brand while you are there, and ask the grandparents not to use phone cleaner apps on it.

The grandparents' phones

If the child also plays on a grandparent's phone, rules have to be set on that phone too, because Ripple rules only apply on the phone where they are set. On a video call the child can open the usage calendar and show you the week.

Child on iPhone

Ripple for iPhone v0.1.5 blocks apps by schedule, can stop apps being deleted, protects against clock changes and uses an unlock code. For daily amounts, Screen Time with Family Sharing lets you change limits from your own iPhone.

Setup steps

Install

On Android download the latest APK and turn on the accessibility service when asked. Ripple needs Android 8.0 or later. If you already have it, update in Settings › About › Check for updates.

Your phone

A sleep schedule, one daily limit for the evening app, an open limit, and strict mode with the code kept by your partner.

The child's phone

Homework and school night schedules, the keep alive steps for that brand, then strict mode with the code kept by you.

Before you leave

Check that the block screen shows when a listed app is opened, and write the code down somewhere safe.

On iPhone

In Ripple for iPhone pick the apps for a schedule. Use Screen Time with Family Sharing for daily amounts.

FAQ

Can I change my child's rules from another city?

Not with Ripple. It has no remote management. You can read the unlock code out on a call, which loosens the rules on that phone for the child.

Can the grandparents turn Ripple off?

With strict mode on, loosening rules or uninstalling needs the unlock code, so keep it yourself.

Will Ripple block WeChat video calls?

Only if you add WeChat to a schedule or limit. You can block only Channels or Moments and keep chats and calls.

What does Ripple for iPhone do?

Ripple for iPhone v0.1.5 blocks apps by schedule, can stop apps being deleted, protects against clock changes and uses an unlock code. It has no daily limits.

Does it cost anything?

Ripple is free, with no ads and no account. More in the FAQ.
