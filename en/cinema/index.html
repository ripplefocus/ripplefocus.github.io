You keep checking your phone at the movies or a show, and kids want the tablet at a children's film too

The film has started and you still reach for the phone, to reply to a message or check the news. The screen lights up and people nearby notice. The same thing happens at concerts and plays. When you take kids to a children's film or play, they get restless and ask for the tablet, and parents sometimes scroll too. This page covers adults setting this up for themselves first, then parents setting it up for their kids. Android is on v0.1.18 and iPhone on v0.1.5. They have different features, so they are covered separately.

Adults: lock the phone before the film starts

Turn on Quick Focus after you sit down

A film is about two hours. For a live show, use the running time on the ticket and add a little extra for the walk out. On Android open Quick Focus, choose lock only the apps I select, add short video, social and news apps, and set 2 hours or two and a half hours. Calls still work, and it lifts when the time is up. Use ticket, payment and map apps first, and leave Taopiaopiao, Maoyan, Alipay, WeChat and maps off the list.

If you often go on weekend evenings, add a schedule

Schedules can be set by day of the week. If you usually go Friday or Saturday night, create a schedule that ticks only those days, from 7 pm to 10:30 pm, and add the apps you keep opening. If the date changes, create a schedule that ticks only today before you leave.

Turn on Complete Lock if you tend to quit early

With Quick Focus alone you can still end it early. On Android v0.1.18 you can turn on Complete Lock for the schedule you use for this outing. While it runs only essential system apps work, the allowed list does not apply, and neither the unlock code nor ending early can lift it. It ends on time. If you still need to show a QR code, start it after you sit down, or skip Complete Lock for this one.

Cut back on other days too

If you reach for the phone outside the cinema as well, give your most used apps a daily limit in minutes, from 1 minute to 12 hours. An app you cannot quit can be set to 0 minutes so it stays closed all day.

Hand the unlock code to someone

With strict mode on, the only way to loosen rules is the unlock code. In strict mode the code is at least 8 characters and works at most 3 times a day, so a family member or friend can keep it. Strict mode also turns on Anti-Uninstall. If you forget the code you can request removal, which takes effect after 72 hours.

Adults on iPhone

iPhone v0.1.5 has no Quick Focus. Before you leave, create a schedule that ticks only today, from the start of the show to the end. The system enforces it even if Ripple is closed. It can also block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, 0 minute limits, Complete Lock or strict mode.

Kids: taking children to a film or a show

Agree on those two hours first

Tell your child that phones and tablets stay in the bag from the start of the show to the end, and they can use them afterwards. You can also plan to talk about the story when it is over. A plain no makes it harder for kids to sit still.

Set it on the child's device before you go

If you want nobody to lift it early, create a schedule on the child's Android device that ticks only today, timed to this film, and add games, short video and cartoon apps. If you often go to weekend children's screenings, add a Saturday and Sunday afternoon schedule as well. For a one-off lock you can also use Quick Focus.

Asking for the tablet in the seat does not help

On Android, turn on Complete Lock for the schedule you use for this outing, add strict mode and Anti-Uninstall, and keep the code yourself. Nobody can lift it before it ends, so you do not have to keep saying no in the dark. Android counts time since boot, so changing the system clock does not end it early.

Parents lock their own phones too

If the adult next to them keeps a bright screen on, kids want the phone more, and people nearby mind it too. Use the steps above on your own phone, or see parents go first.

Kids on iPhone or iPad

iPhone v0.1.5 blocks apps by schedule. Before you leave, create a schedule that ticks only today, from the start of the show to the end, so games and short video stay closed. It can also block deleting apps, protect against clock changes and use an unlock code. It has no Complete Lock, Quick Focus or daily limits. Ripple has no remote management, so set it up on the child's device. On Xiaomi, OPPO, vivo, Huawei and Honor phones, follow the keep alive guide for autostart and battery settings.

Talk about time after the show

You do not have to hand over the tablet as a reward the moment you walk out. If you agreed on a short window later, cap it with a daily limit, or see reward time.

FAQ

I am only going to one film. Do I need an all-day lock?

On Android, use Quick Focus and it lifts when the time is up. If you do not want it lifted early, create a schedule that ticks only today, turn on Complete Lock, and turn that schedule off or delete it afterwards.

Will my ticket code and payments be blocked?

Apps left off the list are not blocked. With Complete Lock on, only essential system apps work and the allowed list does not apply. If you still need to show a QR code, start it after you sit down, or skip Complete Lock for this one.

What if I give in and end it early?

On Android v0.1.18, turn on Complete Lock for the schedule. The allowed list does not apply, the unlock code and ending early cannot lift it, and it ends on time. iPhone v0.1.5 has no Complete Lock.

My child gets restless and asks for the tablet. What helps?

On the child's Android device, create a schedule that ticks only today, turn on Complete Lock plus strict mode and Anti-Uninstall, and keep the code yourself. Nobody can lift it before it ends.

Can I set it remotely from my own phone?

Not now. Ripple settings stay on that phone and there is no remote management, so set it up on the child's phone.

Does it work on iPhone?

iPhone v0.1.5 blocks selected apps by schedule, can block deleting apps, protects against clock changes and has an unlock code. It has no daily limits, 0 minute limits, Quick Focus, Complete Lock or strict mode. Create a schedule that ticks only today before you leave.

Does it cost anything? Do I need an account?

It is free with no ads and no account. More in the FAQ.
