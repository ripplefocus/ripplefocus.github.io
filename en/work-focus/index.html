Scrolling at Work and in Meetings, and Kids Distracted During Homework

Plenty of people reach for the phone while writing something at work and lose twenty minutes to short videos, or keep scrolling under the table in a meeting. At home, kids doing homework or sitting in an online class switch to TikTok or a game the moment a parent looks away. The first part below is for adults setting work hours on their own phone, and the second part is for parents setting homework and online class hours on a child's phone. Both Android and iPhone are covered.

Adults setting work hours on their own phone

Close short videos during work

Put TikTok, YouTube, Instagram and Reddit on the list and close them from 9:00 to 12:00 and 14:00 to 18:00 on workdays, for example. They open again at lunch and after work.

Work apps keep running

Only the apps you list are closed. Slack, Teams, Zoom and email stay untouched if you leave them off the list.

Android: WeChat without Moments and Channels

Work groups and client chats still come through, and only Moments and Channels stay closed during work hours.

Android: 0 minutes for the worst one

On Android v0.1.6 you can set an app's daily limit to 0 minutes so it stays closed all workday. With strict mode on, rules can be loosened only with the unlock code of at least 8 digits, Anti-Uninstall turns on with it, and a forgotten code can be lifted by a request after 72 hours.

iPhone: the system blocks on time

On iOS 16 and later the system blocks listed apps in the background on schedule, even if Ripple is swiped away. The iPhone version is v0.1.5 and does not have daily limits or strict mode yet. Use a cooldown or give the unlock code to a coworker or family member.

Parents setting homework and online class hours on a child's phone

Homework hours

For example short video and game apps closed from 17:00 to 20:30 on school days. When homework is done, a parent enters the unlock code for a while.

Online class with only the class apps

Leave Zoom, Teams or the school's learning app off the list so class runs normally. Put TikTok and games on the list so switching to them during class does nothing.

Android: one game closed all day

For a game you do not want your child playing, set the daily limit to 0 minutes. With strict mode on, the child cannot change the rules on the phone.

Clock changes and uninstalling do nothing

On Android time is counted from device uptime, so moving the clock back does not unlock anything, and uninstall protection is available. See the clock change page. On iPhone the block on deleting apps stops long press removal. See the iPhone page.

Messaging stays open

On Android only WeChat Moments and Channels close, so the child can still message parents, teachers and classmates.

Setup steps

Install Ripple

On Android install the v0.1.13 APK and turn on the accessibility service. On iPhone you need iOS 16 or later and Screen Time permission.

List the distracting apps

Short video, game and social apps. Leave work apps and online class apps off the list.

Set work or homework hours

On Android schedules can differ by day of week, so workdays and weekends can be set apart, and you can also set daily limits.

Set the unlock code

For your own phone give the code to family or a coworker. On a child's phone keep it yourself. On Android you can also turn on strict mode.

Turn on uninstall protection

Anti-Uninstall on Android, and the block on deleting apps on iPhone.

FAQ

I need Slack and Teams at work. Will they be closed too?

No. Only apps on the list are closed, so work apps left off the list keep working.

I only want short videos closed in meetings and still need to reply on WeChat.

On Android WeChat can lose only Moments and Channels, and chats keep working.

My child uses Zoom for online class. Can I close only TikTok and games?

Yes. Leave Zoom off the list, put TikTok and games on it, and set them to close during class hours.

What does 0 minutes mean?

On Android v0.1.6 an app with a 0 minute daily limit stays closed all day. The iPhone version v0.1.5 does not have daily limits yet.

Will my child change the clock or delete Ripple?

On Android changing the clock does nothing because timing uses device uptime, and uninstall protection is available. On iPhone the block on deleting apps stops long press removal.

Does it cost money or need an account?

It is free with no ads and no account. Settings stay on the phone.
