You Keep Loosening Your Own Phone Limits

A lot of people know this one. At night you give short videos 30 minutes a day, and when the time runs out you decide a little more is fine and raise the limit again. Kids do the same thing as soon as a parent sets something up. Ripple v0.1.6 for Android adds two things for this: strict mode and daily limits of 0 minutes. The first part below is for adults using them on their own phone, and the second part is for parents using them on a child's phone. Both Android and iPhone are covered. The iPhone version is still v0.1.5 and does not have these two features, so the page also explains what works there.

Adults setting limits on their own phone

Android: strict mode accepts only the unlock code

Turn on Unlock code only in the Emergency Unlock section of settings. After that, adding time, ending focus early or turning off protection all need the unlock code, and waiting out a cooldown is no longer an option.

Give the unlock code to family or a friend

Strict mode needs an unlock code of at least 8 digits. Tell it to your partner, a roommate or a friend and do not keep it yourself. To loosen a rule you have to ask them first, and most of the time you will not bother.

Android: 0 minutes a day for one app

Daily limits can now be set to 0 minutes, which keeps that app closed for the whole day. Use it to quit one short video app without uninstalling it.

Uninstall protection comes with strict mode

Turning on strict mode also turns on Anti-Uninstall, so removing Ripple does not get you around it.

A way back if the code is lost

If the person holding the code cannot find it either, you can request removal and strict mode lifts after 72 hours. Rules and uninstall protection stay on during the wait, and you can cancel it.

iPhone: schedules and a code someone else keeps

The iPhone version has no strict mode or daily limits. Set a schedule that covers the hours you scroll most and the system blocks the apps in the background. Give the unlock code to family or a friend here too.

Parents setting limits on a child's phone

Android: close one game all day

If a child is hooked on one game, set that game's daily limit to 0 minutes while other apps keep working. Later you can change it back to something like 30 minutes a day.

Android: strict mode cannot be waited out

Normally a rule can be loosened after a cooldown of 15 minutes to 2 hours. With strict mode on the cooldown is not used, so the child has to ask you for the code.

Clock changes and uninstalling do nothing

On Android time is counted from device uptime, see the clock change page, and strict mode turns on uninstall protection as well.

iPhone: schedules and the block on deleting apps

On iPhone set schedules for games and short video apps and enable the block on deleting apps so long press removal stops working. Keep the unlock code yourself. See the iPhone page.

Android: messaging stays open

WeChat can keep chat open while only Channels and Moments close, so there is no need to set a messaging app to 0 minutes.

Setup steps

Install Ripple

On Android install the v0.1.16 APK and turn on the accessibility service. On iPhone you need iOS 16 or later and Screen Time permission.

Pick the app that is hardest to stop

Usually one short video, short drama or game app. Put it on the list.

Android: set its daily limit to 0 minutes

Choose the app under daily limits and set it to 0 minutes. It stays closed all day and is still 0 after midnight.

Set an unlock code of at least 8 digits and hand it over

For your own phone give it to family or a friend. For a child's phone keep it yourself.

Android: turn on Unlock code only

It is in the Emergency Unlock section of settings, and Anti-Uninstall turns on with it. On iPhone set the schedule and enable the block on deleting apps.

FAQ

I keep raising the limits I set. How does Ripple help?

In normal mode loosening a rule needs a wait of 15 minutes to 2 hours. On Android v0.1.6 you can also turn on strict mode so rules can be loosened only with the unlock code. Give the code to family or a friend and you cannot change the rules yourself.

How do I keep one app closed all day?

From Android v0.1.6 a daily limit can be set to 0 minutes. That app stays closed for the whole day and other apps are not affected.

What does the strict mode unlock code need?

Strict mode needs an unlock code of at least 8 digits. The code is stored only on the phone, so the developer cannot recover it.

What if the unlock code is forgotten?

You can request removal and strict mode lifts after 72 hours. Rules stay on and uninstall protection stays on during the wait. Entering the right code cancels the request.

How do I stop my child playing one game at all?

On the child's Android phone set that game's daily limit to 0 minutes, turn on strict mode and keep the code yourself. Changing the clock does nothing and uninstalling Ripple is blocked.

Does iPhone have strict mode and 0 minute limits?

Not yet. The iPhone version is v0.1.5 with schedules, the block on deleting apps and the unlock code. Daily limits, 0 minutes and strict mode are Android features.

Does it cost anything? Do I need an account?

It is free with no ads, needs no account, and all settings stay on the phone.
