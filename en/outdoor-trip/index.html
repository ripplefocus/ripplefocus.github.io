You keep scrolling on a hike or a camping trip, and kids only want the tablet at the campsite

You finally get out for a weekend hike or a night of camping, take a few photos, then sit down and scroll short videos and barely look at the view. On a family outing, kids play on the tablet in the car and ask for it again once they are in the tent. Outdoors you still need maps, the camera and calls, so the phone cannot be locked completely. This page mostly covers locking only the apps you pick. It covers adults setting this up for themselves first, then parents setting it up for their kids. Android is on v0.1.19 and iPhone on v0.1.5. They have different features, so they are covered separately.

Adults: lock only the apps you scroll during the trip

Turn on Quick Focus at the trailhead or campsite

On Android open Quick Focus, choose lock only the apps I select, add short video, social and news apps, and set the length of the trip, such as 3 or 4 hours. Leave maps, camera, weather and the phone app off the list so they keep working. It lifts when the time is up.

If you often go out on weekends, add a schedule

Schedules can be set by day of the week. If you usually head out on Saturday and Sunday, create a schedule that ticks only those days, from 8 am to 5 pm, and add the apps you keep opening. If plans change, create a schedule that ticks only today before you leave.

Skip Complete Lock outdoors

While Complete Lock runs only essential system apps work and the allowed list does not apply, so map and camera apps may not open. If you rely on maps on the trail, Quick Focus or a normal schedule is enough.

Cut back at home too

If you scroll a lot on normal days as well, give your most used apps a daily limit in minutes, from 1 minute to 12 hours. An app you cannot quit can be set to 0 minutes so it stays closed all day.

Hand the unlock code to someone on the trip

With strict mode on, the only way to loosen rules is the unlock code. In strict mode the code is at least 8 characters and works at most 3 times a day, so a family member or friend on the trip can keep it. Strict mode also turns on Anti-Uninstall. If you forget the code you can request removal, which takes effect after 72 hours.

Adults on iPhone

iPhone v0.1.5 has no Quick Focus. Before you leave, create a schedule that ticks only today or Saturday and Sunday, and select short video and social apps. The system enforces it even if Ripple is closed. Maps and camera are not affected if you do not select them. It can also block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, 0 minute limits, Complete Lock or strict mode.

Kids: hiking, camping and day trips with children

Agree on it before you leave

Tell your child that games and short videos will not open on the trail or at the campsite, and the tablet can still be used for photos, looking up plants and checking the map. If they want a cartoon in the tent at night, agree on how long first.

Set a schedule on the child's device

On the child's Android device, create a schedule that ticks only today, from leaving home to getting back, and add games, short video and cartoon apps. If you go out most weekends, create one that ticks only Saturday and Sunday daytime. Keep camera, maps and the phone app off the list.

Use a daily limit for the evening

If you promised one cartoon episode at the campsite, give the cartoon app a daily limit such as 20 minutes. Once it is used up, the app stays closed for the rest of the day. The daytime schedule still applies.

Kids cannot turn it off

On Android, add strict mode and Anti-Uninstall and keep the unlock code yourself. Your child cannot turn off the rules or delete Ripple. Android times rules from device uptime, so changing the clock does not help.

Parents scroll less too

If an adult sits in a camp chair scrolling the whole time, kids want the tablet more. Use the steps above to lock your own scrolling apps, and see parents going first.

Kids on iPhone or iPad

iPhone v0.1.5 can block apps by schedule. Before you leave, create a schedule that ticks only today so games and short videos do not open. It can also block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, Quick Focus or strict mode. Ripple has no remote management, so set it up directly on the child's device. On Xiaomi, OPPO, vivo, Huawei and Honor phones, follow the keep-alive guide for auto-start and battery settings.

Setup steps

Decide which apps you need

Leave maps, camera, weather, the phone app and messaging off the list. Add only the apps you keep scrolling, such as short video, games and social.

Install Ripple

On Android, download the latest APK and turn on the accessibility service as prompted. On iPhone, install v0.1.5, which needs iOS 16 or later.

Set it before you leave

For a one-off trip on Android use Quick Focus. If you go most weekends, create a schedule that ticks only Saturday and Sunday. On the child's device add strict mode and Anti-Uninstall. On iPhone create a schedule for the day before you leave.

After you get home

There is no need to hand over the tablet as a reward right away. If you agreed on some time after the trip, hold it with a daily limit, or see reward time.

FAQ

I need maps on the trail. Will they be locked?

Not unless they are on the list. With Quick Focus set to lock only the apps I select, only the apps you add are locked. Complete Lock ignores the allowed list, so skip it if you need maps outdoors.

Can I still make calls while it is on?

Calls still work during Quick Focus. Put only short video, games and similar apps on the list, and you can reach people in an emergency as usual.

It is a one-day trip. Do I need weekly rules?

On Android use Quick Focus, which lifts on time. You can also create a schedule that ticks only today before you leave, then turn it off or delete it when you get back.

My child wants cartoons at the campsite at night. What then?

Give the cartoon app a daily limit such as 20 minutes, so it closes for the day once used up. Add strict mode and keep the unlock code yourself.

Can I set it up remotely from my own phone?

Not at the moment. Ripple settings stay on the phone they are set on. There is no remote management, so set it up directly on your child's phone.

Does it work on iPhone?

iPhone v0.1.5 can block selected apps by schedule, block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, 0 minute limits, Quick Focus, Complete Lock or strict mode. Create a schedule that ticks only today before you leave.

Does it cost anything? Do I need an account?

It is free, with no ads and no account. See the FAQ for more.
