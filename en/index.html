What It Does

15-Min to 2-Hour Mandatory Cooldown

Tightening rules is instant. Adding time, skipping a focus schedule, pausing protection, or uninstalling requires waiting through a countdown timer (15 min by default, up to 2 hours, doubled for short-video apps) or entering a Friend / Parent Unlock Code.

In-App Feed Blocker & Focus Schedules

Selectively block YouTube Shorts, Instagram Reels, WeChat Channels, and Moments by automatically backing out of short-form feeds while keeping DMs, chats, and long-form videos working. Also includes a 23:30–07:00 sleep schedule and 30-minute per-session whitelist caps.

Two-Tier Anti-Uninstall & Auto-Heal

Basic protection uses Accessibility + Device Admin to block impulsive uninstalls, force-stops, and storage clearing. Optional Advanced Protection uses Android 11+ on-device wireless debugging (no PC needed) to lock package removal and auto-heal in ~2.5s if swiped from Recents.

System Essentials Stay Untouched

Phone calls, SMS, alarms (including full-screen ringing screens), calendar, system camera, keyboards, file pickers, TalkBack, and NFC wallets are permanently allowed and never count toward your whitelist limit.

Monotonic Clock Enforcement: Cooldown timers run on Android’s SystemClock.elapsedRealtime() (time since boot). Changing the phone’s date, time, or timezone will not skip the countdown or reset daily limits early.

Frequently Asked Questions

Why is Ripple distributed as a direct APK instead of on Google Play?

Ripple uses Accessibility Service, Device Administrator, and optional on-device wireless debugging (app_process) to prevent impulsive uninstallation and auto-recover after being killed by aggressive OEM battery managers. Distributing directly via GitHub Releases allows these features to work without compromise. Every release is signed with the same certificate so you can update in-place without disabling protection.

Can parents use Ripple to manage a child’s Android phone?

Yes. Set the daily limits for short-video/game apps and the nightly sleep schedule, set the cooldown waiting time to 2 hours, configure a Parent Unlock Code that only you know, and turn on Anti-Uninstall (plus optional Advanced Protection). Your child will not be able to bypass limits by changing the system time, swiping Ripple away in Recents, clearing app data, or rebooting the phone, while calls, SMS, alarms, and school apps continue working normally.

How does “Advanced Protection” work without a computer or Root?

On Android 11 and above, Android includes built-in Wireless Debugging. When you pair Ripple once using the 6-digit pairing code in the notification shade, Ripple connects to the local ADB daemon on 127.0.0.1 and starts a lightweight background helper (ripple_ss) running under the shell user (UID 2000). This helper locks package uninstallation via DevicePolicyManager, grants WRITE_SECURE_SETTINGS, and automatically restarts Ripple’s Accessibility service within ~2.5 seconds if swiped from Recents.

Does Ripple collect or upload any personal data?

No. Ripple has no user accounts, no cloud servers, no analytics SDKs, and no ads. All rules, daily usage stats, and 7-day block logs stay strictly on your phone. The INTERNET permission is used only when you manually tap “Check for Updates” (which fetches from GitHub Releases) and when connecting to 127.0.0.1 for on-device wireless debugging.

How do I uninstall Ripple if I no longer need it?
  • If Anti-Uninstall is off: uninstall it like any normal Android app.
  • If Anti-Uninstall is on: open Ripple › Settings (设置) › Anti-Uninstall (防卸载) › I want to uninstall Ripple (我想卸载涟漪). Wait for the cooldown timer to finish (or enter your unlock code), and Ripple will automatically release the uninstall lock, deactivate Device Admin, and open the system uninstall dialog.

You will never be locked out or forced to factory-reset your phone.
