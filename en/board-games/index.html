You keep checking your phone during cards, chess and board games, and kids want the tablet while doing puzzles

Friends sit down for cards or a board game and someone is scrolling short videos before the first round ends, so you have to call their name twice when it is their turn. The family finally plays chess, does a jigsaw puzzle or builds with blocks, the adults check messages every few minutes, and the kids keep asking if they can play on the tablet. This page covers adults setting this up for themselves first, then parents setting it up for their kids. Android is on v0.1.20 and iPhone on v0.1.5. They have different features, so they are covered separately.

Adults: lock the apps you scroll before the game starts

Turn on Quick Focus when you deal

On Android open Quick Focus, choose lock only the apps I select, add short video, social and news apps, and set about how long the game will last, such as 2 hours. Leave the phone app off the list so calls still come through. It lifts when the time is up.

For a regular game, add a schedule

Schedules can be set by day of the week. If you play cards with friends every Friday night, create a schedule that ticks only Friday, from 8 pm to 11 pm, and add the apps you keep opening. For a one-off game, Quick Focus is easier.

Keep the scoring app open

Some board games use a phone app for scoring, a timer or the rules. Leave those apps off the list. If you need a chat app to reach people, leave it off too and lock only short video and other social apps.

Family game night can use Complete Lock

If the family is playing chess or a puzzle in the living room and the phone only needs to take calls, turn on Complete Lock for that schedule. While it runs only essential system apps work, the allowed list does not apply, and requests to loosen rules cannot be confirmed.

Hand the unlock code to a friend or partner

With strict mode on, the only way to loosen rules is the unlock code. In strict mode the code is at least 8 characters and works at most 3 times a day, so a friend or partner can keep it. Strict mode also turns on Anti-Uninstall. If you forget the code you can request removal, which takes effect after 72 hours. If you scroll a lot on normal days, give your most used apps a daily limit in minutes, from 1 minute to 12 hours, or 0 minutes for an app you cannot quit.

Adults on iPhone

iPhone v0.1.5 has no Quick Focus. Create a schedule that repeats on a weekday, such as Friday evening, and select short video and social apps. The system enforces it even if Ripple is closed. It can also block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, 0 minute limits, Complete Lock or strict mode.

Kids: chess, puzzles and building blocks with your child

Agree on the time first

Tell your child that for this hour you are playing chess or doing a puzzle together, games and cartoons on the tablet will not open, and afterwards they get the screen time you normally agree on. Let them pick what to play today.

Set a schedule on the child's device

On the child's Android phone or tablet, create a schedule such as Saturday 9 am to 11 am and add games, short video and cartoon apps. Keep the phone app and the app they use to reach you off the list.

Hold tablet games with a daily limit

If your child gets some tablet time each day, give that game a daily limit such as 30 minutes. Once it is used up, the app stays closed for the rest of the day. Set 0 minutes for a game you want gone completely.

Kids cannot turn it off

On Android, add strict mode and Anti-Uninstall and keep the unlock code yourself. Your child cannot turn off the rules or delete Ripple. Android times rules from device uptime, so changing the clock does not help.

Parents stay off the phone too

If an adult replies to messages between moves, kids lose interest fast. Use the steps above to lock your own scrolling apps, and see parents going first.

Kids on iPhone or iPad

iPhone v0.1.5 can block apps by schedule. Create a Saturday morning schedule so games and short videos do not open. It can also block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, Quick Focus or strict mode. Ripple has no remote management, so set it up directly on the child's device. On Xiaomi, OPPO, vivo, Huawei and Honor phones, follow the keep-alive guide for auto-start and battery settings.

Setup steps

Decide which apps you need during the game

Leave the phone app and any app for scoring, timers or rules off the list. Add only the apps you keep scrolling, such as short video, games and social.

Install Ripple

On Android, download the latest APK and turn on the accessibility service as prompted. On iPhone, install v0.1.5, which needs iOS 16 or later.

Set it before you start

For a one-off game on Android use Quick Focus. For a regular card night or family game night, create a schedule that repeats on that weekday, and turn on Complete Lock if you want it stricter. On the child's device add strict mode and Anti-Uninstall. On iPhone create a weekly schedule.

After the game

Scroll afterwards if you like, and hold everyday use with daily limits if you scroll a lot. For kids, see reward time.

FAQ

We score the board game on a phone. Will that app be locked?

Not unless it is on the list. With Quick Focus set to lock only the apps I select, only the apps you add are locked. Complete Lock ignores the allowed list, so the scoring app will not open either. Use paper for scores in that case.

We only play cards now and then. Do I need weekly rules?

On Android use Quick Focus, which lifts on time. You can also create a schedule that ticks only today and turn it off or delete it afterwards.

Can I lift Complete Lock in the middle?

Requests to loosen rules cannot be confirmed while it runs, so you have to wait until the period ends. That makes Complete Lock a fit for a fixed time the whole family agrees on, such as Saturday morning game time.

My child wants the tablet as soon as the game ends. What then?

Give the game a daily limit such as 30 minutes, so it closes for the day once used up. Add strict mode and keep the unlock code yourself.

Can I set it up remotely from my own phone?

Not at the moment. Ripple settings stay on the phone they are set on. There is no remote management, so set it up directly on your child's device.

Does it work on iPhone?

iPhone v0.1.5 can block selected apps by schedule, block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, 0 minute limits, Quick Focus, Complete Lock or strict mode. Create a schedule that repeats each week.

Does it cost anything? Do I need an account?

It is free, with no ads and no account. See the FAQ for more.
