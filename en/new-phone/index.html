New phone in hand? Set the rules before you start using it

When people switch phones, many plan to install fewer short video apps and scroll less this time. Then the old apps are moved over and a few days later everything is the same as before. A child's first phone or tablet goes the same way. If it goes to the child first and the limits come later, the child is already used to playing freely and taking it back is hard. The day a phone arrives is the easiest time to set rules, because there is no habit yet and no argument yet. Ripple lets you set how long and when apps can be used before the phone is really in use. The first part is for adults and the second part is for parents setting up a phone before handing it to a child. Android is on v0.1.16 and iPhone on v0.1.5, with different features, so they are described separately.

Adults: start on day one with the new phone

Decide before moving your apps

When every app from the old phone is moved over, the habits come with it. Install only what you need first. As soon as you install a short video or short drama app you want to control, give it a daily limit in Ripple, in minutes, for example 30 minutes a day. When it is used up the app does not open until midnight.

Keep one app off completely

If an app is impossible to put down once opened, set it to 0 minutes on Android and it will not open all day. You can raise the limit later.

Opening an app dozens of times a day

If you open an app every time you unlock the phone, cap how many times it can open per day and turn on the pause before opening. The screen shows how many times you opened it today and how long you used it. See the open limit page.

Keep the night phone free

Add a schedule from 23:00 to 7:00 so the listed apps do not open. On Android v0.1.16 a schedule can also use Complete Lock, where only system essential apps work until the schedule ends. See the Complete Lock page.

If you might undo it in a few days

On Android with strict mode on, rules can only be loosened with the unlock code. In strict mode the code is at least 8 characters and works at most 3 times a day. Give it to a family member or friend. Strict mode turns on Anti-Uninstall too, and if you forget the code you can request removal, which takes effect after 72 hours.

If the new phone is an iPhone

iPhone v0.1.5 blocks apps by schedule, for example short videos after 22:30, and can block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, open limits or strict mode.

Parents: set it up before the child gets it

Set it up first, then hand it over

When the first phone or tablet comes home, install Ripple, turn on the accessibility service as the app guides you, set the rules, and then give it to your child. From the first day the child knows how long they can play, so you never have to take it back later. See the by age page for different ages.

Make the rules together

Agree with your child how long they can play on school days and on weekends, then give games and short videos a daily limit, such as 30 minutes on school days and 1 hour on weekends. A game you do not want them to play can be set to 0 minutes.

School, homework and bedtime

Add school hours, homework and bedtime schedules so games and short videos do not open then. Leave calls, WeChat chat and alarms off the list so your child can always reach you.

The child cannot change it

On Android with strict mode on, rules can only be loosened with the unlock code, which the parent keeps. With Anti-Uninstall on the child cannot delete Ripple. Ripple on Android counts time since boot, so changing the system clock gives no extra time. Listed apps are also blocked in split screen, floating windows and picture in picture. On OPPO phones a floating window can only be covered and muted and has to be closed by hand.

Keep alive settings on Android phones

Xiaomi, OPPO, vivo, Huawei and Honor phones may close Ripple in the background. After the first install on a new phone, follow the keep alive guide to set auto start and battery optimization.

If the child has an iPhone

iPhone v0.1.5 blocks apps by schedule, blocks deleting apps, protects against clock changes and uses an unlock code. It has no daily limits. Use a homework schedule and a bedtime schedule and leave play time between them. See the parental control page.

Setup steps

Install Ripple

On Android download the latest APK and turn on the accessibility service as the app guides you. On iPhone install v0.1.5, which needs iOS 16 or later.

Keep alive settings

On Android phones from Chinese brands, follow the keep alive guide to allow auto start and turn off battery optimization so Ripple is not closed in the background.

Daily limits and schedules

On Android give the apps you want to control a daily limit or 0 minutes, then add evening, school or homework schedules. On iPhone use schedules.

Unlock code

Adults give the code to a family member or friend. On a child's phone the parent keeps it. On Android turn on strict mode if you want it firmer. On iPhone turn on block deleting apps.

FAQ

I got a new phone. How can I use this chance to scroll less?

Install Ripple first. Give each app you want to control a daily limit as soon as you install it, set the hardest one to 0 minutes, and cap opens for apps you open too often. Add an evening schedule. If you might change the rules yourself, turn on strict mode and give the unlock code to someone in the family.

I bought my child a first phone. What should I set before handing it over?

Install Ripple, turn on the accessibility service, and on Android phones from Chinese brands do the keep alive settings. Agree with your child on daily play time, give games and short videos daily limits, and add school, homework and bedtime schedules. On Android turn on strict mode and Anti-Uninstall and keep the unlock code yourself.

Can I move my Ripple settings from the old phone?

Ripple settings are stored only on the phone. There is no account and no cloud sync, so you need to set them again on the new phone.

Does iPhone have daily limits?

iPhone v0.1.5 has no daily limits. It blocks apps by schedule and can block deleting apps, protect against clock changes and use an unlock code.

How is this different from the by age page?

The by age page covers primary, middle and high school children. This page covers the day a phone arrives and how adults and kids can start with rules from day one.
