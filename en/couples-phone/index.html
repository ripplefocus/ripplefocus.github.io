Couples cutting phone use together

Sitting next to each other while both scroll short video, or one partner still scrolling after the other has gone to sleep, is common. Verbal deals often last a few days. A steadier setup is both of you installing a limit app and giving the unlock code to the other person, so the phone stops the habit first. The first part below is for couples and partners, the second is for two parents setting rules on a child's phone. Android is at v0.1.20 and iPhone at v0.1.5, and the features differ, so both are covered honestly.

Adults: partners holding each other to it

Both install, and each holds the other's unlock code

After both of you install Ripple, set an unlock code of at least 8 digits and give it to your partner. Do not keep the plain code on your own phone. Ending early or adding time needs the cooldown or asking for the code. With strict mode on, loosening rules needs that code.

Use a schedule or one-tap focus for dates and bedtime

Agree on evening dates, a movie night or two hours before sleep, then make a schedule with short video, livestream and game apps in it. For a short break, start one-tap focus and lock only the apps you pick. Calls and chat can stay out.

Give the apps you scroll a daily limit and an open limit

In Daily limits, set how long TikTok, Reels or a game can run each day, from 1 minute to 12 hours in 1 minute steps. You can also set how many opens per day and a short wait before each open. For a full break, set 0 minutes.

Channels and Moments can be limited too

On Android, WeChat Channels and Moments can get a few minutes first, then a reason of at least 10 characters for 5 more minutes, up to 3 times a day. That time counts toward WeChat's daily limit. With strict mode on, continuing needs the unlock code.

Parents: two adults setting a child's phone

Agree on the rules, then install together

Decide sleep and homework schedules and how long games last each day, then install Ripple on the child's phone together. Parents keep the unlock code. Turn on Anti-Uninstall, and strict mode if needed.

Put the same evening rules on your own phones

Kids notice when parents keep scrolling. Parents can use the same evening schedule or one-tap focus, and hold each other's codes. For meals see the mealtime page, and for after-work evenings see the family time page.

A little each day, nothing before exams

Give a game 40 minutes and an open limit so the child can see what is left, and set 0 minutes before exams. On Android, Ripple counts time since the phone started, so moving the clock back does not reset the limits.

If the child uses an iPhone

iPhone v0.1.5 can block apps by schedule, block deleting apps, protect against clock changes and use an unlock code. Open limits, daily limits, 0 minutes, one-tap focus, strict mode and website blocking are Android only for now.

Setup steps (Android v0.1.20)

Both install or update to the latest version

Download the latest Android APK and turn on accessibility when asked. If you have an older build, update in Settings › About › Check for updates. On iPhone install v0.1.5, which needs iOS 16 or later.

Set unlock codes and give them to a partner or parent

The code needs at least 8 digits. Couples give the code to each other. On a child's phone, parents keep it. Turn on strict mode when you want that lock.

Add date, bedtime or homework schedules, plus daily limits

Put short video, livestream and game apps in a schedule or daily limit. Leave chat and calls out. One-tap focus helps when you need a quiet stretch.

Turn on Anti-Uninstall on a child's phone

On Android turn on Anti-Uninstall, and Advanced Protection with a one-time wireless debugging pair if you want a stronger lock. On iPhone turn on the block on deleting apps.

FAQ

How can a couple stop scrolling short video together?

Both install Ripple for Android v0.1.20, give each other the unlock code, set daily limits or 0 minutes on short video and games, and use a schedule or one-tap focus for dates and bedtime. With strict mode on, loosening rules needs the partner's code.

What if only one of us wants to install it?

Start with the person who is ready, and give that phone's unlock code to the other. After one side scrolls less, the other often tries the same setup.

What if two parents disagree on the rules?

Agree on sleep time, homework time and daily game time first, then install together on the child's phone. Only parents keep the unlock code.

How is this different from the family time and mealtime pages?

The family time page is about evenings after work and after school. The mealtime page is about phones at the table. This page is about partners holding each other's unlock codes, and two parents setting a child's phone as a team.

Does the iPhone version have these features?

iPhone v0.1.5 has schedules, the block on deleting apps, clock change protection and an unlock code. Daily limits, open limits, 0 minutes, one-tap focus, strict mode and website blocking are Android only.

Does it cost money or need an account?

It is free with no ads and no account.
