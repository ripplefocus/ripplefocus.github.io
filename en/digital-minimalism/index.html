Want less phone time? Start with opens per day and total minutes

A lot of people try digital minimalism: the phone is full of apps, but only a few waste the day. Deleting them often leads to reinstalling a few days later, or leaving them installed and opening them dozens of times. Digital minimalism starts with rules you can keep. Ripple for Android is at v0.1.18 with open limits, daily limits, 0 minutes, one-tap focus and schedules. iPhone is still v0.1.5 and mainly uses schedules. The first part below is for adults setting it for themselves, the second is for parents on a child's phone, with an honest note on what each platform can do.

Adults: fewer opens first, then fewer minutes

Cap how many times the worst apps open

On Android open Daily limits, pick TikTok, Instagram, Reddit or a short drama app, set a daily open limit such as 5 or 10, and turn on a short wait before each open. The habit of tapping dozens of times a day hits the open count first.

Then cap total minutes

Give the same app a daily time limit, such as 30 minutes or 1 hour. When it is used up it will not open that day. For a full break, set the daily limit to 0 minutes.

Start one-tap focus when you need to work

Before reading, writing or practicing, start one-tap focus on Android and lock only the short video and game apps you pick. Calls and chat can stay available. Fixed hours can use a work or study schedule.

Turn on strict mode if you keep undoing it

With strict mode on, loosening rules needs the unlock code. Use at least 8 digits and give the code to family or a friend. Loosening already needs a wait even without strict mode.

Parents: clear rules for how long kids can play

Decide what they can use and for how long

On a child's Android phone give games and short videos a daily time limit, such as 40 minutes total, plus an open limit such as 3 game opens a day. Use 0 minutes for a full break.

Use schedules for homework and sleep

Add homework and sleep schedules so those apps will not open. During homework you can also start one-tap focus and allow only study apps.

Do not let them undo the rules

Turn on Anti-Uninstall and strict mode, and keep the unlock code with the parent. Changing the clock on Android does nothing. On iPhone turn on the block on deleting apps and set an unlock code.

What iPhone can do now

iPhone v0.1.5 can block apps by schedule, block deleting apps, protect against clock changes and use an unlock code. Open limits, daily limits, 0 minutes, one-tap focus and strict mode are Android only for now.

Setup steps

Install or update

On Android download the latest APK and turn on the accessibility service when asked, or update in Settings › About › Check for updates to v0.1.18. On iPhone install v0.1.5, which needs iOS 16 or later.

Android: pick two or three time sinks

In Daily limits set open counts and daily time, and use 0 minutes when you need a break.

Android: add focus or a schedule

Use one-tap focus when you work, and schedules for fixed hours. Turn on strict mode and give someone else the unlock code if needed.

Child's phone: lock the rules

Turn on Anti-Uninstall and strict mode with the parent holding the code. On iPhone add homework and sleep schedules and block deleting apps.

FAQ

Does digital minimalism mean deleting every app?

No. Many people delete apps and reinstall them later. Ripple can leave the apps installed while limiting opens per day or total minutes, and 0 minutes works for a full break.

What is the difference between open limits and daily limits?

Open limits control how many times an app can launch in a day. Daily limits control total minutes. You can use both. See open limits.

How is this different from the social media detox page?

Social media detox focuses on apps like Instagram and Reddit. This page is about cutting overall phone time, including short video, games, shopping and novels.

Can my kid turn the limits off?

With strict mode on only the unlock code works. Anti-Uninstall adds a wait or the code before removal. Keep the code with the parent.

Can iPhone set open limits and daily limits?

Not in v0.1.5. It has schedules, the block on deleting apps, clock change protection and an unlock code.

Does it cost money or need an account?

It is free with no ads and no account, and settings stay on the phone.
