Kid Can't Stop Playing Mobile Games: Game Schedules and Daily Limits on Android and iPhone

One match ends and the next one starts right away. Homework waits until late, and half an hour of play turns into the whole evening. Some kids also log in with a parent's or a friend's account to get around the game's own limits. This page shows how to limit game apps on the phone itself by schedule or daily time, while calls and messaging keep working.

Settings that help

Block games on a schedule

Games will not open on school nights or at bedtime. Calls and messaging still work.

A fixed amount on weekends

Give games a daily limit. When it runs out the app stays closed for the day.

Switching accounts does nothing

The limit works on the phone, whatever account the game uses.

Clock changes do nothing

Time is counted from device uptime. See the clock change page.

Kids with an iPhone

On iOS 16 and later blocking runs through Apple frameworks. See the iPhone page.

Setup steps

Install Ripple

On Android install the APK and turn on the accessibility service. On iPhone you need iOS 16 or later and Screen Time permission.

Choose game apps

Add Roblox, Minecraft, Fortnite, Brawl Stars, PUBG Mobile and other games.

Set a schedule or daily limit

For example no games from 7 PM to 7 AM on school days and 1 hour a day on weekends.

Set a parent unlock code

The parent keeps the code. Ending the block early or uninstalling asks for it.

Turn on uninstall protection

On Android enable the on-device uninstall guard. On iPhone enable the block on deleting apps.

FAQ

Can my child still message me after games are blocked?

Yes. Only game apps go on the block list. Calls and messaging keep working.

The game already has its own age limits. Why do I need Ripple?

In game limits only apply to the account they are set on. A child who logs in with a parent's account or a friend's account gets around them. Ripple blocks the game app on the phone itself, whatever account is used.

Can I allow a little game time each day?

Yes. On Android you can give a single app a daily limit, for example 1 hour a day on weekends. When it runs out the app stays closed for the rest of the day. On iPhone Ripple currently limits apps by schedule, and daily limits are coming in a later version.

What if my child moves the phone clock back?

It does not help. Ripple counts time from device uptime, so changing the clock does not end the block early or give back used time.

Does it work on iPhone?

Yes, on iOS 16 and later. Ripple uses Apple's FamilyControls, ManagedSettings and DeviceActivity frameworks, so the system blocks the selected games in the background even if Ripple is closed. Unlocking needs a parent code and app deletion can be blocked.

Can my child just uninstall Ripple?

On Android you can turn on uninstall protection on the phone itself without a computer, and removing it needs the parent code. On iPhone the block on deleting apps stops long press removal.
