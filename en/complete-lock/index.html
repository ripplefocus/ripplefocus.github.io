You keep leaving yourself a way out, so lock those hours completely

A lot of people set a focus schedule and a few days later find they are still scrolling during it. Usually they left a gap: one app added to the allowlist just to check something, or the unlock code typed in halfway to end the schedule early. Kids do the same. They keep asking a parent for the code, or open an app that was left on the allowlist and look for videos there. Ripple for Android v0.1.18 has Complete Lock for schedules. When it is on, only system essentials such as phone, messages and alarms can open while that schedule runs. The allowlist stops working, and unlock codes and early end buttons cannot lift it. It ends when the schedule ends. The first part is for adults using it on their own phone and the second part is for parents. Complete Lock is Android only for now. The latest iPhone version is v0.1.5 and does not have it.

Adults: hours when nobody can loosen the rules

Use it only for hours you truly want off the phone

For example 19:00 to 22:00 on evenings before an exam, or an afternoon before a deadline. WeChat and the browser also stay closed during Complete Lock, so keep it for hours when you do not need the phone at all. For sleep or commute hours where you still answer messages, a normal schedule is enough.

The allowlist does not count during the lock

Normally you can keep maps, music or a study app on the allowlist. With Complete Lock on, those apps are blocked too and only system essentials remain. If you need music or to look things up, leave Complete Lock off for that schedule.

Once it starts you cannot end it early

While the lock is running you cannot end, skip, pause, delete or shorten that schedule, and the unlock code does not help. Decide the length first. One or two hours is a good first try.

Calls, messages and alarms still work

System essentials always open, so family can reach you and the morning alarm still rings.

How it differs from strict mode and quick focus

Strict mode means rules can only be loosened with the unlock code in general. Quick focus starts a focus session right away. Complete Lock only applies to the schedule you turn it on for, and even the unlock code cannot lift it.

Parents: no more begging for the code at homework or bedtime

Tell your child first that the phone only makes calls during these hours

For example 21:30 to 06:30 for sleep or 19:00 to 20:30 for homework. Explain that during this time the phone only has calls, messages and alarms, that parents cannot unlock it either, and that it comes back on its own.

Turn on Complete Lock for that schedule on the child's Android phone or tablet

A browser or study app left on the allowlist is blocked during the lock, so it cannot be used as a way into videos. For online class hours that need the tablet, use a normal schedule with an allowlist instead.

Begging does not help

The parent's unlock code cannot lift Complete Lock, and ending early or deleting the schedule does not work either. Kids learn there is nobody to ask, which means fewer arguments. Normal schedules can still be ended early with the code.

Combine it with clock change protection and Anti-Uninstall

Ripple for Android counts time since boot, so moving the system clock forward does not end the schedule early. See the clock change page. Turn on Anti-Uninstall or strict mode so the child cannot remove Ripple.

If your child uses an iPhone

iPhone v0.1.5 has no Complete Lock. It can block apps by schedule, block deleting apps, resist clock changes and use an unlock code. See the parental control page.

Setup steps (Android v0.1.18)

Install or update to v0.1.18

On Android install the latest APK and turn on the accessibility service as guided. With an older version, update from Settings › About › Check for updates. On iPhone install v0.1.5 (iOS 16+), which has no Complete Lock.

Add or edit a schedule

For an adult it can be an evening of exam review. For a child it can be homework or sleep time.

Turn on Complete Lock for that schedule

While it runs only system essentials can open. Start with a shorter length.

Other schedules stay the same

Schedules without Complete Lock keep the allowlist and unlock code as before.

FAQ

I keep adding apps to the allowlist or ending my focus schedule early with the unlock code. What can I do?

On Ripple for Android v0.1.18, turn on Complete Lock for that schedule. While it runs only system essentials such as phone, messages and alarms can open, the allowlist is ignored, and unlock codes and early end cannot lift it. It ends when the schedule ends.

My child keeps asking for the unlock code at homework or bedtime. Can I make it so even I cannot unlock it?

Yes. On the child's Android phone or tablet, turn on Complete Lock for the homework or sleep schedule. During the lock the parent's code does not work, and ending early, deleting or shortening the schedule is blocked. It comes back on its own. Leave it off for online class hours.

Can I use WeChat during Complete Lock?

No. Only system essentials open, so WeChat is blocked too. For hours when you need to answer messages, use a normal schedule and close only Channels and Moments.

Is Complete Lock impossible to get around?

We do not claim that. On some phones a blocked app may show for a moment before it is blocked, and Xiaomi issues have not been retested on a real device yet. System essentials always stay available.

Does the iPhone version have Complete Lock?

No. iPhone is at v0.1.5 with schedules, the block on deleting apps, clock change protection and an unlock code. It does not have Complete Lock, daily limits, 0 minutes, strict mode or quick focus.

Does it cost money or need an account?

It is free, has no ads, and needs no account. See the FAQ for more.
