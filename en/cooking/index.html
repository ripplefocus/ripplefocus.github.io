Less scrolling while cooking and waiting for dinner

The pan is on the stove, yet your hand opens short video or short drama until you smell burning. While a parent cooks, kids nearby or waiting for dinner scroll too. The site also has mealtime, after dinner and family time pages; this page covers cooking and waiting for dinner. The first part below is for adults setting their own cooking limits, the second is for parents whose kids scroll while waiting. Android is at v0.1.20 and iPhone at v0.1.5, and the features differ, so both are covered.

Adults: less scrolling while cooking

Add a cooking schedule first

Put short video, short drama, livestream and games on the list, for example 11:30 a.m. to 12:30 p.m. and 5:30 to 7:00 p.m., or match the hours you usually cook. Those apps will not open during the window. Recipes, calls and chats still work. If weekend cooking is the problem, set only those windows.

Use daily limits and open limits for one more clip

Set how long each hard-to-quit app can run per day, in custom minutes, or set 0 minutes to block it all day. Add how many times it can open, and turn on the short wait before each open so your hand pauses between stirs and a whole dish does not burn.

Use one-tap focus when the stove needs you

When soup is about to boil, oil is hot, or two dishes are going at once, turn on one-tap focus to lock short video and games for a while, then it ends on its own. Recipes and calls still work. See the one-tap focus page.

WeChat Channels and Moments can start with a few minutes

On Android you can limit only Channels and Moments inside WeChat: start with a short allowance, then write a reason to extend, up to 3 times a day, counted toward the WeChat daily limit. In strict mode, extending needs the unlock code. Chat itself still works while you cook.

Turn on strict mode if you undo the rules in the kitchen

Give an unlock code of at least 8 digits to family, and turn on strict mode. Loosening rules then needs their code. Strict mode also turns on Anti-Uninstall. If you forget the code, you can request release after 72 hours. See the strict mode page.

Parents: kids scrolling while waiting for dinner

Add a wait-for-dinner or pre-dinner window for the child

Kids scroll easily while a parent is busy in the kitchen. On the child's phone, add a wait-for-dinner or pre-dinner window such as 5:30 to 7:00 p.m. with short video and games on the list. Parents keep the unlock code.

Leave a small daily budget, or use 0 minutes on heavy cooking days

On normal days leave short video 20 to 40 minutes and a small open limit. On days that stretch into long wait-for-dinner scrolling, temporarily set games and short video to 0 minutes, then change it back once dinner is served.

The living room does not bypass the limits

Schedules and daily limits apply to the apps, so scrolling next to the kitchen is still blocked. On Android turn on Anti-Uninstall, and strict mode if needed. Ripple counts time since the phone started, so moving the clock back does not reset the limits.

Set the same cooking limits on your own phone

If the parent scrolls, the child copies it. Set the same cooking rules on the parent's phone first. For rules at the table, see the mealtime page. After the meal, see the after-dinner page.

If the child uses an iPhone

iPhone v0.1.5 can block apps by schedule, block deleting apps, protect against clock changes and use an unlock code, so a wait-for-dinner schedule works. Open limits, daily limits, 0 minutes, one-tap focus, strict mode, Channels allowance and website blocking are Android only for now.

Setup steps (Android v0.1.20)

Install or update to the latest version

Download the latest Android APK and turn on accessibility when asked. If you have an older build, update in Settings › About › Check for updates. On iPhone install v0.1.5, which needs iOS 16 or later.

Add a cooking or wait-for-dinner schedule

Put short video, short drama, livestream and games on the list. Adults often use midday and evening cooking windows, or match the hours they cook. Kids can use a wait-for-dinner or pre-dinner window. Leave recipes and calls off the list.

Set daily limits and open limits on apps you open most

Give short video, news and social apps a daily cap and an open limit. Apps that take over cooking can be set to 0 minutes. WeChat Channels can use the short allowance with a written reason to extend.

Set unlock codes and turn on Anti-Uninstall for a child

Adults give the code to family, and parents keep the code on a child's phone. On Android turn on Anti-Uninstall, and strict mode if you want a firmer lock. On iPhone turn on the block on deleting apps.

FAQ

I keep scrolling while cooking. What helps?

On Ripple for Android v0.1.20, add a cooking schedule with short video on the list. Add daily limits and open limits on those apps. When the stove needs you, turn on one-tap focus. For a firmer rule, turn on strict mode and give the unlock code to someone else. Recipes and calls still work.

My kid scrolls the whole time waiting for dinner. What can I do?

Add a wait-for-dinner or pre-dinner schedule on the child's phone, keep the unlock code with parents, and turn on Anti-Uninstall. On Android, changing the system clock does not help. For a stricter wait, set short video to 0 minutes and change it back once dinner is served.

How is this different from the mealtime, after-dinner and family-time pages?

The mealtime page covers phones at the table, after dinner covers scrolling after the meal, and family time covers evenings with family. This page covers cooking and waiting for dinner, and it follows Android v0.1.20 daily limits, open limits, one-tap focus, strict mode and Channels allowance. More answers are on the FAQ.

Can I still open a recipe while cooking?

Yes. Put only short video, short drama, livestream and games on the list. Leave recipes, calls and music off the list so they keep working. The limits are there so you do not open a feed between stirs.

Does the iPhone version have these features?

iPhone v0.1.5 has schedules, the block on deleting apps, clock change protection and an unlock code. Daily limits, open limits, 0 minutes, one-tap focus, strict mode, Channels allowance and website blocking are Android only.

Does it cost money or need an account?

It is free with no ads and no account.
