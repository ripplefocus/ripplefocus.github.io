Ripple vs TimeLimit.io and DetoxDroid

TimeLimit.io and DetoxDroid are free, open source Android apps that people on F-Droid and GitHub often recommend. TimeLimit.io is built around parents and children. DetoxDroid is built around making your own phone calmer. Ripple is free too, works on one phone with no account, and covers both a parent setting up a child's phone and an adult limiting their own. I make Ripple, so read this with that in mind. Ripple for Android is v0.1.27 and Ripple for iPhone is v0.1.5. Facts about TimeLimit.io come from its F-Droid listing (v7.9.0) and facts about DetoxDroid from its GitHub README (v3.0.1), both read in November 2026.

What each one is

TimeLimit.io

Open source (GPL-3.0) and on F-Droid, Android 8.0 or later. Apps go into categories, and each category gets allowed hours and time rules, for a day or across several days such as a weekend. Parents can give extra time as a bonus or switch limits off for an hour or a day. It has parent and child user profiles on one device, and one child can be counted across several devices. A connected mode lets a parent view and change settings from another device. Some connected features cost 1 euro a month or 10 euros a year in Germany unless you run your own server. Its listing says it does not work well on some brands, mostly Huawei and Wiko.

DetoxDroid

Open source (GPL-3.0), installed from its GitHub releases. It makes chosen apps grayscale, dimmed and blurred, keeps Do Not Disturb on, interrupts long scrolling sessions and locks that feed for a cooldown, and can make an app wait a few seconds before opening, block it behind a warning or switch it off. A daily time budget locks an app when the budget runs out. It has a pause button with a minimum gap between pauses, an emergency brake that closes the ways out for a set time, a commitment password for settings, a minimal launcher widget and a screen time widget. It is made for your own phone and has no parent and child setup.

Ripple

A free app with no ads, no account and no subscription. It is not open source and is not on F-Droid. On Android (8.0 or later) it has schedules, a daily amount per app including 0 minutes, open limits, a break rule, quick focus, blocked websites, a usage calendar, a mode that closes only WeChat Channels and Moments, and strict mode. On iPhone v0.1.5 it only blocks by schedule, stops apps being deleted, protects the clock and uses an unlock code. It has no parent app and sends no reports.

For a child's phone

Several children or a shared tablet

TimeLimit.io handles this well with child profiles and limits counted across devices. Ripple has one set of rules per phone, so a shared tablet gets the same rules for everyone.

Changing rules from your own phone

TimeLimit.io can do this in connected mode. Ripple cannot. You change rules on the child's phone with the phone in your hand.

Rules the child cannot undo

Turn on strict mode in Ripple and keep the unlock code yourself. Anti-Uninstall turns on with strict mode and needs Android 11 or later. Changing the clock does not end a schedule. A forgotten code is lifted 72 hours after a request. TimeLimit.io uses device admin to notice if it is uninstalled.

Blocking one game completely

In Ripple set the game to 0 minutes and it will not open all day, while other apps keep their own amounts.

Child on iPhone or iPad

TimeLimit.io and DetoxDroid are Android apps. Ripple for iPhone v0.1.5 only blocks apps by schedule with a code you keep. Screen Time with Family Sharing is free and built in and does more.

For your own phone

Making the phone less tempting

DetoxDroid does things Ripple does not, such as grayscale, blur and breaking long scrolling sessions. If you still want to open apps but find them less pulling, start there.

A hard daily limit per app

Ripple gives each app its own daily amount, for example 20 minutes of Instagram and 0 minutes of a game on weekdays, plus a cap on how many times an app opens.

Making the limit stick

In Ripple, loosening a rule or removing the app needs a 15 minute wait or the unlock code. With strict mode only the code works, at most 3 successful uses a day, and a partner or friend can keep it. DetoxDroid has its emergency brake and commitment password for a similar purpose.

How to choose

Choose TimeLimit.io

You want open source parental control with several child profiles or devices and maybe changes from another device.

Choose DetoxDroid

You want open source tools that make your own phone duller to use, with grayscale and breaks from scrolling.

Choose Ripple

You want hard per app limits on Android with no account and nothing sent off the phone, plus an unlock code someone else can keep, for yourself or a child's phone you can set up in person.

Try it first

Install the latest APK, turn on the accessibility service when asked, give one app 30 minutes a day and open it to see the block screen.

FAQ

Is Ripple open source?

No. Ripple is free with no ads and no account, but its source code is not published and it is not on F-Droid. If open source matters most to you, TimeLimit.io and DetoxDroid are good choices.

Can I use Ripple and DetoxDroid together?

They can both be installed, but both rely on an accessibility service, so test on your phone first. I have not tested the pair.

Is Ripple really free?

Yes. No ads, no subscription and no account. More in the FAQ.

What does the iPhone version do?

Ripple for iPhone v0.1.5 blocks apps by schedule, blocks deleting apps, protects the clock and uses an unlock code. It has no daily amounts.
