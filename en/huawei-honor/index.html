Limiting app time on a Huawei or Honor phone

Huawei and Honor phones are common, both as your own phone and as a first phone for a kid. HarmonyOS and MagicOS are strict about background apps, so a limit app can get closed if App launch stays on automatic manage, and a kid can long press its icon to uninstall it. Ripple for Android is at v0.1.20 with daily limits, open limits, 0 minutes, one-tap focus, schedules and strict mode. The first part below is for adults limiting themselves, the second is for parents with a child's Huawei or Honor, and iPhone is covered too. Keep-alive steps are spelled out here, but this page is about limiting app time, not a full keep-alive guide.

Adults: keeping yourself in check on a Huawei or Honor phone

Turn on launch settings and lock Recents first

After you install Ripple and turn on accessibility, open Settings › Apps › App launch, find Ripple, turn off Manage automatically, and allow Autostart, Associated launch and Run in background. In Recents, pull the Ripple card down until a lock appears. If the accessibility switch is greyed out, open Ripple's app info, tap the top right menu, choose Allow restricted settings, then turn accessibility on again.

Give the apps you scroll a daily limit

In Daily limits, tap TikTok, YouTube or a game and set how long you can use it each day, from 1 minute to 12 hours in 1 minute steps. When time is up it stays closed until midnight.

Limit how many times a day you open it

For apps you pick up every few minutes, set a number of opens per day and turn on the wait before opening.

Set 0 minutes for a break, and strict mode if you undo it

Set an app to 0 minutes and it stays closed all day. When you need to work, start one-tap focus and lock only the short video and game apps you pick. Strict mode means only an unlock code can loosen rules. The code has at least 8 digits and you can give it to a friend. It also turns on Anti-Uninstall, and if the code is lost you can request removal after 72 hours.

Parents: your kid has a Huawei or Honor phone

Sleep and homework schedules

Make a 9:30 pm to 7 am sleep schedule and a weekday evening homework schedule on the child's Huawei or Honor with games and short video apps in them. Calls and messaging still work.

A little each day, nothing before exams

Give a game 40 minutes a day and an open limit such as 3 opens, so the child can see what is left, and set 0 minutes before exams. With strict mode on, only the parent's code can loosen rules.

Anti-uninstall and clock changes

With Anti-Uninstall on, removing Ripple needs a wait or the unlock code. For a stronger lock, turn on Advanced Protection on the anti-uninstall page and pair once with wireless debugging on the phone. On Android, Ripple counts time since the phone started, so moving the clock back does not reset the limits.

If the child uses an iPhone

iPhone v0.1.5 can block apps by schedule, block deleting apps, protect against clock changes and use an unlock code. Open limits, daily limits, 0 minutes, one-tap focus, strict mode and website blocking are Android only for now.

Setup steps (Android v0.1.20)

Install or update to v0.1.20

Download the latest APK and turn on the accessibility service when asked. If you have an older version, update in Settings › About › Check for updates. Your rules stay. On iPhone install v0.1.5, which needs iOS 16 or later.

Turn on App launch and lock Recents on Huawei or Honor

Open Settings › Apps › App launch › Ripple, turn off Manage automatically, allow Autostart, Associated launch and Run in background, then lock the Ripple card in Recents. If accessibility is greyed out, allow restricted settings first.

Set daily limits, open limits and schedules

Give apps a daily limit and an open limit, use 0 minutes when needed, then add a bedtime or homework schedule. One-tap focus helps when you need to work.

Turn on Anti-Uninstall, and strict mode if needed

On a child's phone turn on Anti-Uninstall, and strict mode plus Advanced Protection if needed. The parent keeps the code.

FAQ

How do I limit my TikTok time on a Huawei phone?

Install Ripple for Android v0.1.20, turn off Manage automatically in App launch, allow Autostart, Associated launch and Run in background, and lock Ripple in Recents. Then give TikTok a daily limit from 1 minute to 12 hours in Daily limits, and an open limit if you want. For a break, set 0 minutes and turn on strict mode with an unlock code of at least 8 digits held by a friend.

Ripple keeps getting closed on my Honor MagicOS. What do I do?

Open Settings › Apps › App launch, find Ripple, turn off Manage automatically, allow Autostart, Associated launch and Run in background, then lock the card in Recents. See the keep alive guide for full paths.

How do I stop my kid uninstalling the limit app on a Huawei phone?

Turn on Anti-Uninstall in Ripple. Removing it then needs a wait or the parent's unlock code. For a stronger lock, turn on Advanced Protection and pair once with wireless debugging. With strict mode on, only the parent's code can loosen rules.

Can I limit WeChat Channels and Moments too?

Yes on Android. You can give Channels and Moments a few minutes first, then write a reason of at least 10 characters to get 5 more minutes, up to 3 times a day. That time counts toward WeChat's daily limit. With strict mode on, continuing needs the unlock code.

Do split screen and floating windows get blocked? Are website limits reliable?

From Android v0.1.8, a blocked app in split screen, a floating window or picture-in-picture is blocked too. On OPPO phones the floating window is only covered and muted for now, and you still close the window yourself. Website blocking exists from v0.1.12 and was tested on Chrome in the emulator. Built-in Chinese browsers and pages inside apps may not be blocked, so limit the browser app itself in that case.

How is this different from the Xiaomi page?

The Xiaomi and Redmi page covers Autostart and battery saver on HyperOS and MIUI. This page covers App launch and Recents lock on Huawei HarmonyOS and Honor MagicOS. The limit features are the same on Android v0.1.20.

Does the iPhone version have these features?

iPhone v0.1.5 has schedules, the block on deleting apps, clock change protection and an unlock code. Daily limits, open limits, 0 minutes, one-tap focus, strict mode and website blocking are Android only.
