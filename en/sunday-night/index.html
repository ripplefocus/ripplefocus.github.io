Dreading Monday, so the phone keeps you up on Sunday night

For many people Saturday goes fine and Sunday evening is the hard part. Work is tomorrow, you feel a bit low, and you lie in bed scrolling short videos as if that keeps Monday away. Then it is 1 a.m., you cannot get up on Monday, and the whole day feels heavy. With kids it often looks like this: on Sunday evening they remember the homework is not done, they do it with the phone next to them, and they go to bed later than on school nights. Ripple schedules can be set by day of the week, so you can tick Sunday only and leave the other days alone. The first part is for adults setting limits on their own phone and the second part is for parents. Android and iPhone have different features, so they are described separately.

Adults: a schedule just for Sunday evening

Tick Sunday only

Add a schedule, choose Sunday as the only day, for example 22:30 to 23:59. Short video, short drama and live streaming apps close at that time. Other days stay as they are.

Keep WeChat if you need it

You may still check a work group on Sunday night. Put WeChat on the allowlist, and on Android close only Channels and Moments, so you can reply but not scroll.

If you tend to undo it

On Android, with strict mode on, rules can only be loosened with the unlock code, which works at most 3 times a day. You can give the code to a family member or friend.

If you want the phone out of reach

Android v0.1.16 can turn on Complete Lock for that schedule. While it runs only system essentials such as phone, messages and alarms open, the allowlist is ignored, the unlock code cannot lift it, and it ends on its own. Leave it off if you need work messages on Sunday night.

If daytime is the problem too

On Android you can give short video apps a daily limit, such as 60 minutes, after which they close for the day. Daily limits apply every day and cannot be set per weekday.

Parents: no more phone next to the homework on Sunday night

Set aside Sunday afternoon for homework

On the child's phone or tablet add a Sunday only schedule, for example 15:00 to 17:30, when games and short videos do not open. Homework gets done in the afternoon and there is no rush at night.

Put the phone away earlier on Sunday night

Add another Sunday schedule, such as 21:00 to 23:59, when games and videos are blocked and only calls, messages and alarms remain, so the child goes to bed at the usual school night time.

When the child begs

On Android with strict mode on, the parent's unlock code is the only way to loosen rules. If the schedule has Complete Lock, even the parent's code cannot lift it, so there is no point in asking.

Clock changes and uninstalling

Ripple for Android counts time since boot, so moving the system clock forward does not end the schedule early. See the clock change page. With Anti-Uninstall on, the child cannot delete Ripple.

If your child uses an iPhone

iPhone v0.1.5 blocks apps by schedule, and schedules can be set by weekday. It can also block deleting apps, resist clock changes and use an unlock code. It has no daily limits, strict mode or Complete Lock. See the parental control page.

Setup steps

Install or update

On Android install the latest APK and turn on the accessibility service as guided. With an older version, update from Settings › About › Check for updates. On iPhone install v0.1.5 (iOS 16+).

Add a schedule

Choose Sunday as the only day and set the hours. Add an evening one, and for a child an afternoon homework one too.

Pick the apps to block

Put short video, short drama, live streaming and game apps on the list. Apps you still need go on the allowlist.

Add a stricter layer if needed

On Android turn on strict mode or Complete Lock for that schedule. On iPhone set an unlock code.

FAQ

Every Sunday night I dread work and scroll short videos until midnight. What can I do?

Add a Ripple schedule for Sunday only, for example 22:30 to 23:59, so short video, short drama and live streaming apps do not open. Other days are not affected. On Android you can add strict mode or turn on Complete Lock for that schedule.

Can I limit my phone only on Sundays and not on workdays?

Yes. Schedules are set by day of the week, so tick only Sunday. Both Android and iPhone support this. Daily limits on Android apply every day and cannot be set for Sunday only.

My child only does homework on Sunday night and plays on the phone at the same time. How should I set it up?

Add two Sunday only schedules on the child's phone: an afternoon homework schedule and an evening one for an earlier bedtime, with games and short videos blocked. On Android add strict mode or Complete Lock so begging for the code does not help.

I still need the work chat on Sunday night. Can I block only short videos?

Yes. Put WeChat on the allowlist and block only the short video apps. On Android you can also close Channels and Moments. Complete Lock blocks WeChat too, so do not use it in this case.

Does it work on iPhone?

Yes, v0.1.5 on iOS 16 or later. It blocks apps by schedule, blocks deleting apps, resists clock changes and supports an unlock code. It does not have daily limits, 0 minutes, strict mode, quick focus or Complete Lock.

Does it cost money or need an account?

It is free, has no ads, and needs no account. See the FAQ for more.
