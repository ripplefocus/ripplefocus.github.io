Less scrolling at bedtime and first thing in the morning

You scroll in bed and it is past 1 a.m. The alarm rings and the first thing you open is the same short video app. The first part below is for adults setting their own bedtime and morning limits, the second is for parents whose kids stay up or scroll in bed after the alarm. Android is at v0.1.14 and iPhone at v0.1.5, and the features differ, so both are covered. The site also has separate bedtime and morning pages; this page ties both ends together.

Adults: less scrolling at night and after waking

Add an overnight bedtime schedule first

Put short video, short drama, livestream and games on the list, for example 11:00 p.m. to 7:00 a.m. Those apps will not open during the window. Alarms and calls still work. Schedules can cross midnight and repeat on the weekday the start time falls on.

Add a morning window too

Many people start scrolling again as soon as the bedtime window ends. Add a morning schedule such as 6:30 to 8:00 a.m., or end the bedtime window after you leave home, so short video stays closed when you wake up.

Use daily limits and open limits for one more round

Set how long each hard-to-quit app can run per day, in custom minutes, or set 0 minutes to block it all day. Add how many times it can open, and turn on the short wait before each open so your hand pauses.

WeChat Channels and Moments can start with a few minutes

On Android you can limit only Channels and Moments inside WeChat: start with a short allowance, then write a reason to extend, up to 3 times a day, counted toward the WeChat daily limit. In strict mode, extending needs the unlock code.

Turn on strict mode if you undo the rules at night

Give an unlock code of at least 8 digits to family or a roommate, and turn on strict mode. Loosening rules then needs their code. Strict mode also turns on Anti-Uninstall. If you forget the code, you can request release after 72 hours.

Parents: kids up late and scrolling after the alarm

Set a school-night sleep schedule, and a later one for weekends

On the child's phone, add a school-night bedtime window such as 9:30 p.m. to 6:30 a.m. so short video and games close on time. Friday and Saturday can use a later window. Parents keep the unlock code.

Add a morning window so bed scrolling after the alarm stops

Many kids keep scrolling after the alarm. Add a morning schedule, or end the sleep window when they should leave. Leave the clock app off the list.

Leave a small daily budget, or use 0 minutes when you need it stricter

On normal days leave short video 30 to 40 minutes and a small open limit. Before exams or when sleep is a mess, set games and short video to 0 minutes.

Turn on Anti-Uninstall and clock protection

On Android turn on Anti-Uninstall, and strict mode if needed. Ripple counts time since the phone started, so moving the clock back does not reset the limits. On iPhone turn on the block on deleting apps.

If the child uses an iPhone

iPhone v0.1.5 can block apps by schedule, block deleting apps, protect against clock changes and use an unlock code, so sleep and morning schedules work. Open limits, daily limits, 0 minutes, one-tap focus, strict mode, Channels allowance and website blocking are Android only for now.

Setup steps (Android v0.1.14)

Install or update to the latest version

Download the latest Android APK and turn on accessibility when asked. If you have an older build, update in Settings › About › Check for updates. On iPhone install v0.1.5, which needs iOS 16 or later.

Add a bedtime schedule and a morning schedule

Put short video, short drama, livestream and games on the list. Adults often use 11:00 p.m. to 7:00 a.m.; school nights for kids can start earlier. Add a separate morning window, or end the night window after they leave.

Set daily limits and open limits on apps you open most

Give short video, news and social apps a daily cap and an open limit. Apps that keep you up can be set to 0 minutes. WeChat Channels can use the short allowance with a written reason to extend.

Set unlock codes and turn on Anti-Uninstall for a child

Adults give the code to family, and parents keep the code on a child's phone. On Android turn on Anti-Uninstall, and strict mode if you want a firmer lock. On iPhone turn on the block on deleting apps.

FAQ

I keep scrolling short video in bed. What helps?

On Ripple for Android v0.1.14, add an overnight bedtime schedule with short video on the list. Add daily limits and open limits on those apps. For a firmer rule, turn on strict mode and give the unlock code to someone else.

I wake up and scroll as soon as the bedtime window ends. What then?

End the bedtime window later, or add a morning schedule. You can also lower the daily limit so a short morning scroll uses it up.

My kid hides under the covers at night and scrolls after the alarm. What can I do?

Add school-night sleep and morning schedules, keep the unlock code with parents, and turn on Anti-Uninstall. On Android, changing the system clock does not help. Before exams, set short video to 0 minutes.

How is this different from the separate bedtime and morning pages?

The bedtime and morning pages each cover one end. This page covers both staying up scrolling and scrolling first thing after waking, and it follows Android v0.1.14 daily limits, open limits, strict mode and Channels allowance.

Does the iPhone version have these features?

iPhone v0.1.5 has schedules, the block on deleting apps, clock change protection and an unlock code. Daily limits, open limits, 0 minutes, one-tap focus, strict mode, Channels allowance and website blocking are Android only.

Does it cost money or need an account?

It is free with no ads and no account.
