A phone-free day each week, and a family deal to skip tablets on Saturday morning

Some people want one fixed day a week for themselves, no short video and no games, time for a hike, a book or family, and still find their hand on the phone. Some families agree that nobody touches phones or tablets on Saturday morning, and the kids come asking within an hour. Ripple schedules can be set by day of the week, so you pick only that day and the rest of the week stays normal. This page covers adults setting a phone-free day for themselves first, then parents setting one for their kids. Android is on v0.1.18 and iPhone on v0.1.5. They have different features, so they are covered separately.

Adults: one day a week off the phone

Start with half a day

A whole day without the phone is hard at first. Try Sunday 8 am to noon, keep it for a few weeks, then stretch it to the full day.

Pick only that day

Create a schedule, tick only Sunday, and add short video, short drama, games and shopping apps to the list. Weekdays are not affected. Calls, messages, maps and ride apps can stay on the allowed list.

Turn on Complete Lock if you tend to quit early

On Android v0.1.18 you can turn on Complete Lock for this schedule. While it runs only essential system apps work, the allowed list does not apply, and neither the unlock code nor ending early can lift it. It ends on time. Skip it if you only want to block a few apps.

Cut back on other days too

Outside the phone-free day, give your most used apps a daily limit in minutes, from 1 minute to 12 hours. An app you cannot quit can be set to 0 minutes so it stays closed all day.

Hand the unlock code to someone

With strict mode on, the only way to loosen rules is the unlock code. In strict mode the code is at least 8 characters and works at most 3 times a day, so a family member or friend can keep it. Strict mode also turns on Anti-Uninstall. If you forget the code you can request removal, which takes effect after 72 hours.

Adults on iPhone

iPhone v0.1.5 blocks selected apps by schedule, enforced by the system even if Ripple is closed. It can also block deleting apps, protect against clock changes and use an unlock code. It has no daily limits, 0 minute limits, Complete Lock or strict mode.

Kids: the family's phone-free time

Agree on it together

Decide with your child which day and hours are phone and tablet free, and plan what to do instead, like the park, cooking or a board game. A plain no is hard for kids to accept.

Set the schedule on the child's device

Create a schedule, tick only Saturday, set 9 am to noon, and add games, short video and cartoon apps. School day homework and sleep schedules are set separately, see homework time.

Asking again does not help

On Android, turn on Complete Lock for this schedule so nobody can lift it before it ends, and you do not have to keep saying no. Add strict mode and Anti-Uninstall, and keep the code yourself. Android counts time since boot, so changing the system clock does not end it early.

Parents join in

If parents keep scrolling during phone-free time, kids will not see it as fair. Set the same schedule on your own phone as described above, or see parents go first.

Kids on iPhone or iPad

iPhone v0.1.5 blocks apps by schedule, so games and short video stay closed during the agreed hours. It can also block deleting apps, protect against clock changes and use an unlock code. It has no Complete Lock or daily limits. Ripple has no remote management, so set it up on the child's device. On Xiaomi, OPPO, vivo, Huawei and Honor phones, follow the keep alive guide for autostart and battery settings.

Setup steps

Choose the day

Pick a day or half day for yourself. Families with kids decide together and write down the start and end time.

Install Ripple

On Android download the latest APK and turn on the accessibility service when prompted. On iPhone install v0.1.5, which needs iOS 16 or later.

Create a schedule for that day only

Create a schedule, tick only that day and add the apps to block. On Android turn on Complete Lock for a stricter version, and add strict mode and Anti-Uninstall on the child's phone.

Adjust after a few weeks

If it sticks, make it longer. If it is too hard, shorten it first. Keeping it going matters more than the length.

FAQ

Can it apply only on Sunday and leave weekdays alone?

Yes. Schedules are set by day of the week. Tick only Sunday and nothing is blocked on other days.

What if I give in and end it early?

On Android v0.1.18, turn on Complete Lock for the schedule. The allowed list does not apply, the unlock code and ending early cannot lift it, and it ends on time. iPhone v0.1.5 has no Complete Lock.

Can I still take calls and use maps?

A normal schedule lets you keep calls, maps and ride apps on the allowed list. With Complete Lock on only essential system apps work and the allowed list does not apply, so leave Complete Lock off if you need those apps.

My child keeps asking for the tablet during the agreed time. What helps?

On the child's Android device, turn on Complete Lock for that schedule plus strict mode and Anti-Uninstall, and keep the code yourself. Nobody can lift it before it ends.

Can I set it remotely from my own phone?

Not now. Ripple settings stay on that phone and there is no remote management, so set it up on the child's phone.

Does it work on iPhone?

iPhone v0.1.5 blocks selected apps by schedule, can block deleting apps, protects against clock changes and has an unlock code. It has no daily limits, 0 minute limits, Complete Lock or strict mode.

Does it cost anything? Do I need an account?

It is free with no ads and no account. More in the FAQ.
