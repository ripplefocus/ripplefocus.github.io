Less scrolling after dinner for adults and kids

Dinner ends and short video starts on the sofa for an hour or two. Kids finish homework and join in, or hide in their room scrolling. The first part below is for adults setting their own after-dinner limits, the second is for parents whose kids scroll after homework or behind a closed door. Android is at v0.1.13 and iPhone at v0.1.5, and the features differ, so both are covered. The site also has mealtime and family time pages; this page covers the stretch from after dinner until bedtime.

Adults: less scrolling after dinner

Add an after-dinner schedule first

Put short video, short drama, livestream and games on the list, for example 7:00 to 9:30 p.m. Those apps will not open during the window. Chats and calls still work. If you also want limits during the meal, start the window a bit earlier so it meets the mealtime setup.

Use daily limits and open limits for one more round

Set how long each hard-to-quit app can run per day, in custom minutes, or set 0 minutes to block it all day. Add how many times it can open, and turn on the short wait before each open so your hand pauses.

WeChat Channels and Moments can start with a few minutes

On Android you can limit only Channels and Moments inside WeChat: start with a short allowance, then write a reason to extend, up to 3 times a day, counted toward the WeChat daily limit. In strict mode, extending needs the unlock code.

Use one-tap focus when you want the evening clear

If you need to get something done or sit with people after dinner, turn on one-tap focus to lock short video and games for an hour or two, then it ends on its own.

Turn on strict mode if you undo the rules after dinner

Give an unlock code of at least 8 digits to family or a roommate, and turn on strict mode. Loosening rules then needs their code. Strict mode also turns on Anti-Uninstall. If you forget the code, you can request release after 72 hours.

Parents: kids scrolling after homework or in their room

Add a window after homework

Once homework is done, scrolling often starts. On the child's phone, add an after-dinner to bedtime window such as 7:30 to 9:30 p.m. with short video and games on the list. Parents keep the unlock code.

Leave a small daily budget, or use 0 minutes when you need it stricter

On normal days leave short video 30 to 40 minutes and a small open limit. When homework drags, exams are near, or evenings are a mess, set games and short video to 0 minutes.

A closed bedroom door does not bypass the limits

Schedules and daily limits apply to the apps, so scrolling behind a closed door is still blocked. On Android turn on Anti-Uninstall, and strict mode if needed. Ripple counts time since the phone started, so moving the clock back does not reset the limits.

Set the same after-dinner window on your own phone

When everyone is scrolling on their own, set the same after-dinner rules on the parent's phone first so the child sees the same rule. For the meal itself, see the mealtime page.

If the child uses an iPhone

iPhone v0.1.5 can block apps by schedule, block deleting apps, protect against clock changes and use an unlock code, so an after-dinner schedule works. Open limits, daily limits, 0 minutes, one-tap focus, strict mode, Channels allowance and website blocking are Android only for now.

Setup steps (Android v0.1.13)

Install or update to the latest version

Download the latest Android APK and turn on accessibility when asked. If you have an older build, update in Settings › About › Check for updates. On iPhone install v0.1.5, which needs iOS 16 or later.

Add an after-dinner schedule

Put short video, short drama, livestream and games on the list. Adults often use 7:00 to 9:30 p.m.; for kids, match the window from after homework to bedtime. Start earlier if you also want limits during the meal.

Set daily limits and open limits on apps you open most

Give short video, news and social apps a daily cap and an open limit. Apps that take over the evening can be set to 0 minutes. WeChat Channels can use the short allowance with a written reason to extend.

Set unlock codes and turn on Anti-Uninstall for a child

Adults give the code to family, and parents keep the code on a child's phone. On Android turn on Anti-Uninstall, and strict mode if you want a firmer lock. On iPhone turn on the block on deleting apps.

FAQ

I keep scrolling short video after dinner. What helps?

On Ripple for Android v0.1.13, add an after-dinner schedule with short video on the list. Add daily limits and open limits on those apps. For a firmer rule, turn on strict mode and give the unlock code to someone else.

The whole family scrolls after dinner. How do we cut it together?

Set after-dinner schedules on both adult and child phones. Put the same rules on the parent's phone, and turn on Anti-Uninstall for the child. Leave a small daily limit on normal days, or use 0 minutes when you need it stricter.

My kid scrolls right after homework, or hides in their room. What can I do?

Add an after-dinner to bedtime schedule, keep the unlock code with parents, and turn on Anti-Uninstall. On Android, changing the system clock does not help. When homework drags or exams are near, set short video to 0 minutes.

How is this different from the mealtime and family-time pages?

The mealtime page covers phones at the table, and family time covers evenings after work. This page covers scrolling from after dinner until bedtime, and it follows Android v0.1.13 daily limits, open limits, strict mode and Channels allowance.

Does the iPhone version have these features?

iPhone v0.1.5 has schedules, the block on deleting apps, clock change protection and an unlock code. Daily limits, open limits, 0 minutes, one-tap focus, strict mode, Channels allowance and website blocking are Android only.

Does it cost money or need an account?

It is free with no ads and no account.
