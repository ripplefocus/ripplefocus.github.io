Limiting apps on a tablet, for adults and for kids

People set limits on their phone and forget the tablet. For adults the tablet is often the screen for shows in bed or on the sofa, where one episode turns into four. For kids it is often the family tablet that was bought for online classes and now mostly runs cartoons and games. Ripple for Android is v0.1.19 and runs on Android tablets with the same APK as on phones. Ripple for iPhone is v0.1.5. I make Ripple, and I have tested it on far fewer tablets than phones, so if something looks wrong on yours, please write to me. The first part is for adults and the second part is for parents.

Adults: the tablet next to the bed

Give the video apps a daily limit

Put YouTube, Netflix or whatever you watch on a daily limit, for example 90 minutes. When the time is used up the app shows the block screen until the next day.

An end time for the evening

Add a schedule such as 23:00 to 7:00 with the video apps on the list. The tablet still works for reading and music if you leave those apps off the list.

Fewer reopenings

If you keep picking the tablet up to check one app, add a daily open limit and a pause before opening. Each open waits 5 to 30 seconds and shows the time used today. See open limits.

When you tend to undo it

Without strict mode, loosening a rule needs a wait of 15 minutes by default, up to 2 hours, or the unlock code. With strict mode on only the code works, with at most 3 successful uses a day. Strict mode also turns on Anti-Uninstall, which needs Android 11 or later.

Rules on the phone too

Ripple rules stay on the device where you set them. If the same app is on your phone, set a limit there as well, or the evening just moves to the phone.

See where the time went

The usage calendar on Android shows each day's total and each app's time, opens and blocks, kept on the device for 365 days.

Parents: the family tablet

A tablet for one child

Set it like a child's phone: a schedule for homework time and a school night schedule such as 21:00 to 7:00, with games and video apps on the list, and a daily limit on the main game. A 0 minute limit blocks one app for the whole day.

A tablet the whole family shares

Ripple has no user profiles. Rules apply to the whole tablet, whoever is holding it, so a limit set for the kids also limits you on that tablet. Many families keep the shared tablet for the kids' rules and watch their own shows elsewhere.

Online classes keep working

Leave the class app and the browser off the schedule list, and add only games, short video and live streaming apps. If the child switches to videos in the browser, add the sites to Blocked websites, one domain at a time.

Kids who know the settings

Turn on strict mode and keep the unlock code yourself. Anti-Uninstall turns on with it. Time is counted from device uptime, so changing the tablet's clock does not end a schedule. A forgotten code can be requested and is lifted after 72 hours.

Check it together

Ripple has no remote management. Once a week open the usage calendar on the tablet with your child and look at the time and block counts per app.

If the tablet is an iPad

Ripple for iPhone v0.1.5 is built for iPhone and I have not tested it on iPad, so I cannot promise it works there. On iPad, Screen Time with Family Sharing gives you Downtime and app limits from your own device.

Setup steps

Install

On an Android tablet download the latest APK and turn on the accessibility service when asked. Ripple needs Android 8.0 or later. If you already have it, update in Settings › About › Check for updates.

Keep it running

Some tablets stop background apps. Follow the keep alive guide for your brand so blocks stay on.

Adults: a daily limit and an end time

Give the show apps a daily limit, add a night schedule, and turn on strict mode only if you keep loosening the rules.

Parents: lists and strict mode

Add homework and night schedules with games and video apps, keep class apps off the list, then turn on strict mode and keep the code.

FAQ

Does Ripple work on Android tablets?

Ripple for Android uses the same APK on phones and tablets and needs Android 8.0 or later. It has been tested on far fewer tablets than phones, so please report anything that looks wrong.

Can I set different rules for each person on a shared tablet?

No. Ripple has no user profiles, so rules apply to the whole tablet whoever is using it.

Will online class apps still work?

Yes, as long as you leave them off the schedule and limit lists. Only the apps you add are blocked, unless you turn on Complete Lock.

Does it work on iPad?

Ripple for iPhone v0.1.5 has not been tested on iPad. For iPad use Screen Time and Family Sharing.

Does it cost anything?

Ripple is free, with no ads and no account. More in the FAQ.
