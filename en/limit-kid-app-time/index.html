How Do I Limit One App on My Child's Phone to a Set Time Each Day?

Install Ripple v0.1.30 on the child's Android phone, open Daily Limits, pick the app and set the most minutes a day. When it is used up the app stays closed until midnight. It is free, has no ads and needs no account. Changing the phone clock does nothing, and uninstalling needs the countdown or the unlock code a parent keeps. Rules live on the child's phone, so a parent cannot view or change them remotely from their own phone.

The direct answer for Android

Step 1, install on the child's phone

Install the APK and follow the guide to turn on the accessibility service and device admin. A parent does this with the child's phone in hand.

Step 2, set the daily limit

On Daily Limits tap the game or video app and set 1 minute to 12 hours. The child can see how much is left today.

Step 3, weekdays and weekends

Since Android v0.1.25 you can set it by weekday, for example 0 minutes on school days and 60 minutes on Saturday and Sunday.

Step 4, uninstall protection with a parent held code

Uninstalling then needs the countdown or the code. For a child who must not change anything, turn on strict mode so loosening needs the parent's unlock code.

Common ways kids get around limits

Changing the clock

Timing follows time since boot, so turning the clock back does nothing.

Split screen, floating windows, picture in picture

Since v0.1.8 a blocked app in these windows is still blocked and the time counts toward the day.

Asking for a bit more

Loosening any limit needs a wait or the parent's unlock code.

Long press to uninstall

Uninstall protection stops it until the countdown ends or the code is entered.

What about WeChat

Only Channels and Moments

Chat keeps working so the child can still reach a parent. Channels and Moments can get a few minutes first, then 5 more minutes after a reason, up to 3 times a day.

Calls and alarms

Phone, SMS, alarm and camera always work.

If the child has an iPhone

What iPhone v0.1.5 does

Needs iOS 16 or later. It blocks apps on a schedule through the system, can stop the app being deleted, and loosening needs a wait or the unlock code.

What it does not do

A daily limit per app is Android only for now. On iPhone you can use Apple's built in Screen Time for daily limits.

Compared with other free options

Google Family Link

Free, lets a parent view and change things remotely, and needs the child's Google account. Ripple needs no account but is set on the child's phone.

Built in Digital Wellbeing

Free and simple, but a limit can be ignored and a child can learn the PIN. Ripple makes you wait or enter the parent's code.

Teen modes in TikTok or WeChat

They cover one app. Ripple covers several together.

FAQ

How do I limit one app on my child's phone to a set time a day?

Install Ripple v0.1.30 on the child's Android phone, open Daily Limits, pick the app and set the most minutes a day. When it is used up it stays closed until midnight. Free, no ads, no account.

Can the child get around it by changing the clock?

No. Ripple times from boot, so turning the clock back does nothing.

How do I stop the child switching it off or deleting it?

Turn on uninstall protection so uninstalling needs the countdown or the unlock code a parent keeps. Add strict mode so loosening any rule needs the code, at least 8 digits.

Can school days be 0 and weekends one hour?

Yes. Since Android v0.1.25 limits can be set by weekday.

Can I do daily limits for one app on a child's iPhone?

Ripple on iPhone v0.1.5 has no daily limit yet, only schedules and stopping deletion. For daily limits use Apple's Screen Time.

Can a parent manage it remotely from their own phone?

No. Ripple has no account or cloud, so rules are set on the child's phone. For remote control use Google Family Link, which needs the child's Google account.
