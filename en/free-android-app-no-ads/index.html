Is There a Free Android App Blocker With No Ads?

Yes. Ripple for Android v0.1.28 is free, has no ads or subscription, and needs no account. Rules and usage stay on the phone. It is not in an app store, so you install the APK from the website. Below is what it does, what it does not do, and how to set it up.

The direct answer

How free is free

Daily limits, open limits, 0 minutes, strict mode, uninstall protection, Quick Focus and per weekday limits are all free. There is no paid tier and no ads.

Compared with the built in limits

Digital Wellbeing is also free and easy for one app. The difference is that its limit can be ignored at the time. Ripple makes you wait 15 minutes or enter an unlock code a friend holds.

Full features are Android only

Daily limits, 0 minutes, strict mode and Channels only blocking are Android v0.1.28 features. iPhone v0.1.5 blocks by schedule and can stop the app being deleted.

You install an APK

Download ripple-latest.apk and allow unknown apps the first time. Existing installs update under Settings, About, Check for updates and keep their rules.

What it can limit on Android

A daily limit per app

On Daily Limits pick TikTok, a game or any app and set 1 minute to 12 hours. When it is used up the app stays closed until midnight. Since v0.1.25 weekdays and weekends can differ.

Closed all day

Set an app to 0 minutes to keep it closed all day.

Opens per day

Set a maximum number of opens a day and a short pause of 5 to 30 seconds before each open.

Only WeChat Channels and Moments

Chat and payments keep working. Channels and Moments can get a few minutes first, then 5 more minutes after writing a reason, up to 3 times a day.

What if I turn it off myself

Uninstall protection

To uninstall Ripple you wait out the countdown or enter an unlock code held by someone else.

Clock change resistance

Timing follows time since boot, so turning the clock back does nothing.

Strict mode

Loosening rules needs an unlock code of at least 8 digits kept by family or a friend, with at most 3 successful uses a day. A forgotten code can be recovered after a 72 hour request.

Calls and alarms keep working

Phone, SMS, alarm and camera always work.

Three steps

Download

Open the website on your phone and download the Android APK.

Follow the permission guide

Turn on the accessibility service and device admin. On Chinese phones also allow autostart and set battery to unrestricted.

Pick apps and set limits

On Daily Limits pick the apps you scroll most. Add uninstall protection and strict mode if you tend to undo rules.

Honest notes

Not every case is tested

Some new features were tested on an emulator and one phone only. The release notes say what is not yet verified on real devices.

About the count

Once a day on first open the app sends an anonymous count with platform, version, install age range and a random ID. No usage content.

FAQ

Is there a free Android app blocker with no ads?

Yes. Ripple for Android v0.1.28 is free with no ads, no subscription and no account. Rules and usage stay on the phone. You install the APK from the website.

Can a free app limit each app per day?

Yes. On Daily Limits set 1 minute to 12 hours for any app. When it is used up the app stays closed until midnight. 0 minutes keeps it closed all day.

Is there one I cannot just switch off?

Ripple makes you wait 15 minutes or enter an unlock code held by someone else before loosening a rule. Strict mode allows only the code, and uninstall protection covers uninstalling.

Does it work on iPhone?

iPhone v0.1.5 needs iOS 16 or later and only blocks by schedule and stops deletion. Daily limits, 0 minutes and strict mode are Android only for now.

Does it collect my usage?

No ads. Rules and per app usage stay on the phone. Once a day it sends an anonymous count with platform, version, install age range and a random ID.
