Short Dramas, Live Streams and Mobile Games Until Midnight

Short drama episodes last a minute or two and each one ends right before something happens, so your thumb moves to the next one. A live stream keeps talking and two hours pass. A mobile game round takes twenty minutes, and you want another one whether you win or lose. Kids get pulled in the same way and find it even harder to stop. The first part below is for adults limiting their own phone, and the second part is for parents limiting a child's phone. Both Android and iPhone are covered.

Adults limiting their own phone

Daily limits for dramas and streams

On Android put ReelShort, TikTok, Twitch or similar apps on the list with 30 minutes a day, for example. When the time is used up the app stays closed for the rest of the day, and opening it in bed only shows the block screen.

0 minutes for the game you cannot put down

On Android v0.1.8 you can set an app's daily limit to 0 minutes so the game stays closed all day. Nothing is uninstalled, and your account and saves are still there.

Close them at night on a schedule

Android and iPhone both support schedules, for example 23:00 to 7:00 with dramas, streams and games closed while alarms and calls keep working.

Android: strict mode with someone else holding the code

Limits you set yourself are the easiest to undo at midnight. With strict mode on Android, rules can be loosened only with the unlock code of at least 8 digits, and Anti-Uninstall turns on with it. Give the code to a family member or friend. If it is really lost, a request lifts it after 72 hours.

iPhone: the system blocks on time

On iOS 16 and later the system blocks listed apps in the background on schedule, even if Ripple is swiped away. The iPhone version is v0.1.5 and does not have daily limits, 0 minutes or strict mode yet. Give the unlock code to a family member.

Parents limiting a child's phone

Daily limits for games and dramas

On Android give games 30 minutes a day on school days and short drama and streaming apps 20 minutes, for example. They close on their own when time runs out, so you do not have to keep reminding.

One game closed completely

For the game your child plays the most, set the daily limit to 0 minutes on Android so it stays closed all day. With strict mode on, the child cannot change the rules on the phone.

Homework and bedtime schedules

On Android and iPhone you can close games, dramas and streams during homework time after school and at night.

Clock changes and uninstalling do nothing

On Android time is counted from device uptime, so moving the clock back does not unlock anything, and uninstall and force stop protection are available. See the clock change page. On iPhone the block on deleting apps stops long press removal. See the iPhone page.

Calls and chats stay open

Leave the phone app and WeChat off the list so your child can always reach you. On Android only WeChat Moments and Channels can be closed while chats keep working.

Setup steps

Install Ripple

On Android install the v0.1.15 APK and turn on the accessibility service. On iPhone you need iOS 16 or later and Screen Time permission.

List the drama, streaming and game apps

Leave calls, chat apps, maps and school apps off the list.

Set daily limits or schedules

On Android set daily limits, give the hardest app 0 minutes, or set schedules by day of week. On iPhone set schedules.

Set the unlock code

For your own phone give the code to family or a friend. On a child's phone keep it yourself. On Android you can also turn on strict mode.

Turn on uninstall protection

Anti-Uninstall on Android, and the block on deleting apps on iPhone.

FAQ

I watch short dramas inside TikTok. Can I close only the dramas?

Ripple works per app. If TikTok is on the list the whole app follows the rules. Standalone drama apps like ReelShort or DramaBox can be listed too.

Will a 0 minute limit delete my game saves?

No. It only keeps the app closed for the day. Nothing is uninstalled and app data is untouched.

Will my child change the clock or delete Ripple?

On Android changing the clock does nothing because timing uses device uptime, and uninstall protection is available. On iPhone the block on deleting apps stops long press removal.

Can iPhone set daily limits or 0 minutes?

Not yet. The iPhone version v0.1.5 has schedules, the block on deleting apps, clock change protection and the unlock code.

What if I forget the strict mode code?

Send a request in the app and it is lifted after 72 hours.

Does it cost money or need an account?

It is free with no ads and no account. Settings stay on the phone.
