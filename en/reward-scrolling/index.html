Ten minutes of scrolling as a reward, and two hours are gone

You finally sent the report, or the chores are done, so you open short videos for ten minutes. The next time you check it is almost midnight and the rest of the evening's plans move to tomorrow. Kids do the same. A parent says half an hour of games after homework, the child cannot stop when the time is up, asks for one more round, and it ends in an argument. A small reward is fine. Stopping on time is the hard part. Ripple lets you set the reward time in advance, and when it runs out the apps simply do not open, so you do not have to rely on willpower and parents do not have to take the phone away. The first part is for adults and the second part is for parents. Android is on v0.1.19 and iPhone on v0.1.5, with different features, so they are described separately.

Adults: decide the size of the reward in advance

Turn the reward into a daily limit

On Android give short video and short drama apps a daily limit in minutes, for example 30 minutes a day. When it is used up they do not open until midnight. How much reward you get today is decided when you set it.

Pause before opening

Turn on the pause before opening for these apps. The screen shows how many times you have opened the app today and how long you have used it. Seeing those numbers is often enough to remember you already had your reward. You can also cap opens per day, see the open limit page.

Set a time when it has to stop

Rewards usually happen in the evening, and that is when they run past midnight. Add a schedule from 23:00 to 7:00 so short video, short drama and game apps close, and they come back in the morning. Leave calls, WeChat chat and alarms off the list.

If you tend to give yourself one more round

On Android with strict mode on, rules can only be loosened with the unlock code. In strict mode the code is at least 8 characters. Give it to a family member or friend. It works at most 3 times a day. Strict mode turns on Anti-Uninstall too, and if you forget the code you can request removal, which takes effect after 72 hours.

On iPhone

iPhone v0.1.5 has no daily limits or open limits. Use a schedule as the end point instead, for example short videos blocked after 22:30, so any reward has to happen before then. Give the unlock code to someone in the family.

Parents: half an hour means half an hour

Agree on the time with your child first

Talk about how long they can play after homework and on weekends, then give games and short videos a daily limit on the child's phone or tablet, such as 30 minutes on school days. When it runs out the apps close, and the child knows this is what you both agreed, so you do not have to keep reminding.

Block games during homework

Add a schedule on school days from 19:00 to 20:30 when games and short videos do not open. After it ends, the daily limit controls how long they can play. See the homework page.

When the child wants one more round

On Android with strict mode on, rules can only be loosened with the unlock code, which the parent keeps, so the child cannot change the limit. If one game is especially hard to put down lately, set it to 0 minutes for a while and raise it later.

Clock changes, split screen and uninstalling

Ripple for Android counts time since boot, so moving the system clock forward does not add time. See the clock change page. Listed apps are also covered in split screen, floating windows and picture in picture. On OPPO phones a floating window can only be covered and muted and has to be closed by hand. With Anti-Uninstall on, the child cannot delete Ripple.

If your child uses an iPhone

iPhone v0.1.5 blocks apps by schedule, blocks deleting apps, resists clock changes and supports an unlock code. It has no daily limits. You can put the reward between two schedules, for example homework from 19:00 to 20:30 and bedtime from 21:00, which leaves half an hour to play. See the parental control page.

Setup steps

Install or update

On Android install the latest APK and turn on the accessibility service as guided. With an older version, update from Settings › About › Check for updates. On iPhone install v0.1.5 (iOS 16+).

Android: daily limits for reward apps

Set how many minutes a day short videos, short dramas and games can be used. Add the pause before opening and an open limit if you like.

Add a schedule where it stops

Adults add an evening schedule. For kids add a homework schedule and a bedtime schedule. On iPhone put the reward time between two schedules.

Set the unlock code

Adults give the code to family or a friend. Parents keep the code for the child's phone. On Android turn on strict mode if you want it firmer, and on iPhone turn on block deleting apps.

FAQ

I plan to scroll for ten minutes as a reward and it always becomes an hour or two. What can I do?

On Android give short video and short drama apps a daily limit in Ripple, such as 30 minutes, after which they close for the day. Turn on the pause before opening, which shows today's open count and usage. Add an evening schedule so they close at night. If you might change the rules, turn on strict mode and give the unlock code to a family member.

My child gets half an hour after homework but will not stop. How should I set it up?

Agree on a daily amount with your child, then give games and short videos a daily limit on the child's Android phone or tablet. Add a schedule for homework time when those apps do not open. Keep the unlock code yourself, and with strict mode on the child cannot change it.

Can daily limits be set in minutes?

On Android yes, anywhere from 1 minute to 12 hours, or 0 minutes to block the app for the whole day. iPhone v0.1.5 has no daily limits.

How do I control reward time on iPhone?

iPhone v0.1.5 only blocks by schedule. Set a homework schedule and a bedtime schedule and leave the play time between them, then turn on block deleting apps and an unlock code.

How is this different from the open limit page?

The open limit page is about opening the same app again and again all day. This page is about a short break after finishing something that never ends, handled mainly with daily limits and schedules.

Does it cost money or need an account?

It is free, has no ads, and needs no account. See the FAQ for more.
