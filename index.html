它能做什么

应用内局部拦截与专注时段

支持只拦「微信视频号 / 朋友圈、YouTube Shorts、Instagram Reels」短视频流，点击即自动退回上一页，正常微信聊天支付与看长视频不受影响；同时自带 23:30–07:00 睡眠专注时段与白名单单次 30 分钟上限。

每日时长与休息提醒

给抖音、快手、TikTok、YouTube、游戏等设每天最多用多久，用完当天就打不开，0 点重新计算；也支持连续用一会儿后强制歇几分钟。

两层防冲动卸载

默认两步开启无障碍和设备管理器即可拦住卸载与清数据；可选开启本机无线调试「高级保护」，不用连电脑就能锁住系统卸载开关，划掉后台约 2.5 秒自动恢复。

系统必需的不受影响

电话、短信、闹钟、日历、系统相机、输入法、文件选择器、屏幕阅读器和系统钱包一直能用，不占白名单名额，早上闹钟响铃绝不拦截。

把规则改严立刻生效。放松规则（加时长、提前结束、关保护或卸载）要先等一会儿，默认 15 分钟（可调至 2 小时，短视频类高风险 App 等待时间翻倍，基于开机单调时钟计算，改手机时间无效），或者输入亲友与家长保管的解锁码。

怎么安装

  1. 下载安装包用手机浏览器打开本页，点「下载安卓版 v0.1.5」直接下载 ripple-v0.1.5.apk（后续版本可在「设置 › 关于 › 检查更新」里直接覆盖升级）。
  2. 允许「安装未知应用」第一次装时，系统会提示「出于安全考虑，已禁止安装此来源的应用」。点「设置」，打开「允许来自此来源的应用」，再返回。
  3. 点「安装」手机可能还会提示未上架商店的风险，见下面各品牌的说明。
  4. 打开涟漪，跟着设两步打开「无障碍」和「设备管理器」，一分钟就好，不用连电脑。
Android 13 / 14 / 15 提示「受限设置（无障碍灰色不可点）」怎么办？① 先在系统无障碍列表点一下「涟漪」触发系统提示；② 打开手机「设置 › 应用管理 › 涟漪」，点右上角「⋮」菜单选择「允许受限设置」（验证锁屏密码），再返回无障碍即可正常开启。

常见问题

为什么不在应用商店里？

涟漪要用无障碍和设备管理器来拦住 App、防止一时冲动卸载，很多应用商店不收这类工具。直接从这里下载，更新也更快。每个版本都用同一个签名，也能在「设置 › 关于 › 检查更新」里直接覆盖升级，规则不会丢。

适合家长用来管孩子看手机吗？

适合。家长给孩子设好每天短视频或游戏的时长和晚上睡觉时段后，可以把等待时间调到 2 小时、设好只有家长知道的「亲友解锁码」，并开启防卸载（及可选的「高级保护」）。之后孩子自己改系统时间、从后台划掉涟漪、进设置清数据或重启手机都绕不过去，同时又不影响正常接打电话和早上闹钟。

我的数据会被上传吗？

不会。涟漪没有账号、没有统计、没有广告。你设的规则、每个 App 用了多久、拦下的记录，都只存在你这台手机上。

网络只用在两处：可选的「高级保护」要通过无线调试连接手机自己；手动点「检查更新」时会读取 GitHub 上公开的版本信息。都不会上传你的数据。

会影响打电话、闹钟吗？

不会。电话、短信、闹钟、日历、相机、输入法、系统文件选择器、系统钱包和设置一直能用，专注时段里也一样。微信、支付宝这类可以自己加到「专注时可用」里。

真想卸载怎么办？
  • 没开「防止一时冲动卸载」：像普通 App 一样直接卸载。
  • 开着的话：打开涟漪 › 设置 › 防卸载 › 我想卸载涟漪。先等一会儿（默认 15 分钟），或者请亲友或家长输入解锁码，涟漪会自动解开保护，然后弹出系统的卸载确认。

不会出现必须恢复出厂设置的情况。

更新要先卸载旧版吗？

不用。下载新版直接安装，或者在应用内点「设置 › 关于 › 检查更新」，都会直接覆盖升级，规则和防卸载保护原样保留。

English Overview · Ripple for Android Full English Page →

Ripple (涟漪) is a free, local-only Android self-control and screen-time blocker built for adults quitting short-form video doomscrolling and parents managing a child’s phone.

  • 15-min to 2-hour mandatory cooldown before relaxing any rule, pausing schedules, or uninstalling (powered by Android’s monotonic clock SystemClock.elapsedRealtime(), so changing the system time does nothing). Supports an optional Friend / Parent Unlock Code.
  • Per-session caps for whitelisted apps (30 min by default) so allowing messaging apps during sleep hours does not turn into scrolling built-in video feeds all night. Phone calls, SMS, alarms, camera, calendar, keyboards, and NFC wallets are always allowed.
  • Two-tier anti-uninstall protection: Basic 2-step setup (Accessibility + Device Admin) with no PC required, plus optional Advanced Protection using Android 11+ on-device wireless debugging (app_process daemon) that locks package removal and auto-heals within ~2.5 seconds if swiped from Recents.
  • 100% free, no ads, local-only data: No accounts, no cloud sync, and no analytics SDKs.
