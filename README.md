## 主要功能

- **应用内短视频流局部拦截（v0.1.5 新增）**：支持一键只拦「微信视频号、微信朋友圈、YouTube Shorts、Instagram Reels」，点进短视频流自动退回上一页，正常微信聊天支付、看 YouTube 长视频与发 Instagram 私信不受影响；关闭已开启的局部拦截同样需等待 15 分钟倒计时或输入亲友解锁码。
- **专注时段**：在设定的时间段里，只允许打开你事先选好的少数几个 App。
- **每日时长**：给短视频、游戏等 App 设定每天最多可用的时长，用完当天打不开，0 点重置。
- **防一时冲动卸载（支持家长解锁码与高级保护）**：开启后，想放松规则或卸载涟漪需要先等一会儿（15 分钟～2 小时，高风险应用翻倍，改系统时间无效），或输入由亲友/家长保管的解锁码；可选本机无线调试「高级保护」，杀后台或重启手机都能自动恢复。
- **系统必需不受影响**：电话、短信、闹钟、日历、相机、输入法、系统钱包和系统设置始终可用。
- **本地隐私保护**：无账号、无广告、无统计，所有规则与使用记录只保存在你的手机本地。
